# 文稿 -> Qwen TTS 声音设计输入

为声音设计应用生成两个且仅两个业务输入：`text`（文稿）和 `voicePrompt`（声音提示词）。不要生成语言字段，不让用户选择声音、性别或语速。

## 生成原则

先从全文推断讲述者、受众、用途和情绪变化，再用清晰、具体、客观的自然语言描述声音。描述应多维但简洁，每个词都必须对应可听见的特征：

- 【人设】：声音性别、准确年龄段、身份或用途、气质。外形词必须转译为声音特征，不能只写“胖乎乎”“漂亮”。
- 【音色特征】：音调高低、明暗、厚薄、共鸣、气息或颗粒感，选 2-4 个协调特征。
- 【风格】：稳定的交流方式、距离感和表演强度；不得混入只属于本篇的临时情绪。
- 【情感】：本篇的情绪起点、变化、峰值和收束；不要只写“开心”“悲伤”等单一标签。
- 【节奏】：整体语速、局部快慢、重音、停顿、句尾处理；只写文稿能够支持的变化。

【人设】【音色特征】【风格】组成固定声线；【情感】【节奏】组成随本篇文稿变化的表演指令。五项必须互相协调：不得同时出现“高亢/低沉”“轻快/迟缓”“克制/全程强烈”等冲突要求。

优先使用“偏高、清脆、语速偏快”等可感知词，禁止“好听、高级、有感觉”等主观词，禁止模仿名人或真实人物。每项只写最有辨识度的信息，不堆叠近义形容词，不使用空泛的“情绪饱满、抑扬顿挫”。

可优先采用这些参考方向，但不要机械套词：

- 知识讲解：可信、清晰、亲和；重点加重，复杂处放慢。
- 新闻纪实：克制、沉稳、客观；信息密集处稳定推进。
- 情感故事：温润、细腻、有呼吸感；转折前停顿，结尾收束。
- 产品介绍：自然、有分享欲、不叫卖；卖点清晰，节奏明快。
- 悬疑叙事：低沉、克制、带警觉；线索处放慢并留短停顿。
- 轻松娱乐：明亮、有互动感；短句推进，包袱前后留节奏差。

参考表达（只学习精度，不机械套用）：

- 儿童女孩：【人设】5-6 岁乖巧小女孩，带自然的动画角色感。【音色特征】音调偏高，清脆轻薄，带柔和奶气。【风格】软糯亲近，略带撒娇但不刻意卖萌。【情感】明快好奇，表达愿望时期待感稍增强。【节奏】语速偏快，短句轻巧跳跃，关键词自然上扬。
- 儿童男孩：【人设】5-6 岁憨厚小男孩，质朴真诚。【音色特征】中高音，厚实圆润，带轻微鼻腔共鸣和奶气。【风格】朴实笨拙，不油滑、不成人化。【情感】认真中带一点迟钝的可爱，结尾真诚收住。【节奏】语速偏慢，短句略有顿挫，思考处短暂停顿。
- 产品介绍：【人设】25-35 岁女性产品体验者，亲和可信，面向普通消费者分享。【音色特征】中高音，清亮温润，气息自然。【风格】像真实体验后的推荐，不使用播音腔或叫卖腔。【情感】开头自然亲切，讲到核心收益时分享欲增强，结尾笃定收束。【节奏】整体中速，卖点词加重，复杂信息放慢，句间留自然停顿。

保持文稿原样，生成一次声音设计任务：

```json
{
  "text": "完整文稿",
  "voicePrompt": "【人设】年龄感、身份、气质和表达目的。【音色特征】高低、明暗、厚薄、气息和辨识度。【风格】稳定的表达习惯。【情感】本篇情绪起点、转折、潜台词和收束。【节奏】整体语速、局部快慢、重音、停顿和结尾方式。"
}
```

`voicePrompt` 必须严格按【人设】【音色特征】【风格】【情感】【节奏】的顺序输出。不得改写文稿，不输出分析、备选方案、多角色任务或其他字段。
