# Seed Audio Reference 选择手册

Reference 包含两层：先选择与任务最接近的官方提示词范式，再决定是否用 `@音频N` 锁定声音。不要把所有写法混成一个万能模板。

## 先选 Reference 范式

| 用户任务 | 首选 Reference 范式 | 必须继承的写法 |
|---|---|---|
| 刑侦、悬疑、电话对话 | 刑侦悬疑片 | 先定义人物声线，再写持续环境、配乐、电话空间处理和追问节奏 |
| 宫廷、古装权谋、多人冲突 | 宫廷试药 | 逐角色写身份与威严层级，动作声紧贴台词前后，音乐负责压迫感 |
| 神话、玄幻、法术场面 | 神话 | 写角色混响、空间尺度、法术声顺序和庄重或张扬的表演差异 |
| 科幻、机械广播、未来空间 | 未来科幻片 | 写机械空间底声、电子提示音序列、广播或对讲机的声音处理 |
| 古装喜剧、强喜剧对白 | 古装喜剧片 | 用乐器和卡通音效承接动作与包袱，角色反应和接话节奏优先 |
| 双人访谈、聊天播客 | 双人播客 | 保留自然停顿、附和、笑声和抢接话，不擅自加入影视化配乐 |
| 新闻专题、现场追踪 | 新闻现场追踪 | 区分理性旁白与现场证人，音乐可在证词处停下，现场声保持纪实 |
| 单人访谈、长段口述 | 单人播客 | 保留口语停顿和语气词，节奏自然稳定，不把口语改成播音稿 |
| 调查讲述、案件复盘 | 悬疑讲述 | 旁白推进信息，关键物证配明确动作声，真相前后改变音乐或环境 |
| 深情回忆、人物独白 | 深情独白 | 用同一参考音贯穿，写轻笑、吸气、停顿、哽咽等连续情绪过程 |
| 直播带货 | 直播带货 | 主播与助播分别定义，保留短促附和，背景音乐极弱，实物声具体 |
| 多角色剧情且有参考音 | 剧情片 | 最多三个角色分别绑定 `@音频N`，逐句写攻击、退让、打断与动作声 |
| 一个参考音演多个角色 | 单人多角色演绎 | 共同保留基础音色辨识度，用年龄、明暗、节奏和情绪区分角色 |
| 广告音效按时间卡点 | 音效卡点 | 每段对白和关键音效写清时间区间，声音事件与品牌落点对齐 |
| 哭腔、气声、强弱递进 | 情绪推进 | 写情绪起点、转折、呼吸和句尾状态，并用时间区间锁定关键表现 |
| 旁白与角色切换 | 叙事切分 | 每次切换明确当前身份、音色、叙述距离和时间区间 |
| 旁白、音乐、引擎渐强渐弱 | 旁白推进 | 逐段写人声强弱、音乐变化和引擎声进入退出的位置 |

## 先判断任务

| 任务 | Reference 选择 | 重点写法 |
|---|---|---|
| 从零创建角色声音 | 不使用参考音，或只使用用户明确指定的风格参考 | 用文字固定年龄感、声线、质感、口音和基础风格 |
| 单人旁白、广告、OS、独白 | 1 个参考音 | 锁定该人的音色；情绪和节奏按内容重新导演 |
| 双人对白 | 2 个参考音 | `@音频1`、`@音频2` 分别绑定一个角色，并在每句台词前明确说话角色 |
| 三人对白 | 3 个参考音 | `@音频1`、`@音频2`、`@音频3` 分别绑定一个角色，并在每句台词前明确说话角色 |
| 四人以上内容 | 最多锁定 3 个主要角色 | 次要角色用文字音色，或拆成多段提示词 |
| 同一角色跨语言 | 1 个角色参考音 | 保留音色身份，另写目标语言和目标口音，不把原语言发音习惯硬套过去 |
| 只模仿情绪或节奏 | 1 个表演 Reference | 明确“只参考情绪/节奏/风格，不参考音色” |
| 完整短剧或影视声轨 | 1-3 个角色参考音 | Reference 负责角色声音；音乐、环境和音效主要用文字描述 |
| 纯音乐或纯音效 | 不使用角色参考音 | 直接描述乐器、节奏、空间、声音事件和卡点 |

## Reference 能控制什么

### 音色 Reference

用于提供角色的声音参考。提示词写：

`角色A是青年女性、普通话、声线明亮，饰演者为@音频1。`

适合：连续剧角色、广告代言人、固定旁白、跨语言复刻。

### 情绪 Reference

只借用表演状态，不借用说话人的身份。提示词写：

`只参考@音频1中逐渐压抑转为爆发的情绪变化，不参考其音色和口音。`

适合：用户提供了理想表演样例，但生成角色必须使用另一种声音。

### 风格 Reference

只借用整体表达方式，例如纪录片、直播带货、港式刑侦、播客闲谈、ASMR 或有声书。提示词写：

`参考@音频1的克制纪实风格和留白节奏，不复刻其中人物音色。`

### 节奏 Reference

用于复用语速变化、停顿、接话或爆点位置。提示词写：

`参考@音频1由慢到快的推进节奏和关键句前的停顿，不参考其音色。`

## 多 Reference 规则

1. 按用户上传或提供的顺序编号，不自行交换。
2. 先写映射，再写正文：`女儿饰演者为@音频1，陈大发饰演者为@音频2。`
3. 一个主要角色只绑定一个音色 Reference。
4. 一个音色 Reference 默认只绑定一个主要角色。
5. 同一角色的旁白、OS 和对白仍使用同一个音色 Reference，只改变距离、情绪和表演方式。
6. Reference 中存在音乐或噪声时，不默认要求模型复刻这些声音；只写用户真正需要参考的部分。
7. 用户没有说明 Reference 用途时，根据任务最小化使用：角色参考音优先用于角色声音特征，情绪、节奏和背景声由当前台词导演说明决定。

## 角色基准音

创建新角色时，不需要情绪包，只写一个唯一基准音提示词：

- 6-12 秒左右；
- 一个人说一段自然完整的话；
- 中性、稳定、清楚；
- 无音乐、无环境音、无音效、无混响；
- 能听出年龄感、声线、音色质感和口音；
- 不用极端愤怒、哭喊、耳语或尖叫作为身份基准。

后续的愤怒、悲伤、开心、惊恐等都在正式内容提示词里写，不更换角色基准音。

## 选择优先级

1. 用户明确指定 Reference 的用途。
2. 用户提供的角色与 Reference 对应关系。
3. Reference 本身可确认的音色、情绪、风格和节奏特征。
4. 当前内容类型的最小合理推断。

不能确认时，不虚构 Reference 的性别、年龄、口音或情绪；只写可确定的用途。
