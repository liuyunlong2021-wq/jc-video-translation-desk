# Seed Audio 提示词标准

一段好的提示词必须同时回答：生成什么、谁在说、参考谁、怎么说、什么时候说、身处哪里、同时发生什么声音、最后如何结束。

## 标准顺序

### 1. 全局目标

第一句写清：

- 输出语言或口音；
- 内容类型；
- 目标总时长；
- 整体风格和表演强度。

示例：

`生成一段约45秒的中文双人悬疑短剧完整声音轨，表演强度高，台词清晰，整体节奏由克制逐渐推向爆发。`

### 2. Reference 锁定

紧接着写每个 Reference 的角色和用途：

`林夏饰演者为@音频1，周野饰演者为@音频2。两人全程保持固定声线，不能串音；情绪变化不能改变年龄感、口音和声音身份。`

只参考某个维度时写排除项：

`只参考@音频3的紧张节奏和停顿方式，不参考其音色、语言和背景声。`

### 3. 声场和声音设计

完整声轨才写这一层。说明：

- 室内外和空间距离；
- 环境底声；
- 音乐风格、乐器、情绪和音量关系；
- 必须出现的关键音效；
- 转场时声音怎样变化。

不要只写“加点音乐”“加点音效”。

### 4. 按顺序写内容

每一段使用：

`角色（情绪过程，强度，节奏和动作）：“原文台词。”`

有精确时间时，把时间区间放在它控制的声音之前：

`[2.0s:5.0s] 角色（表演要求）说：“原文台词。”`

时间区间必须是 `[开始秒:结束秒]`，开始小于结束、顺序清楚且不重叠。需要空白时直接写：

`[5.0s:6.0s] 保持安静。`

### 5. 结尾约束

写清最后一个声音事件和禁止增加的内容：

`最后用一记短促低沉的音乐顿点结束，不增加旁白、对白或口号。`

## 角色固定层

角色固定层包括：

- 声音年龄感；
- 声线高低、明暗、厚薄；
- 清亮、温润、低沉、粗粝、沙哑等核心质感；
- 稳定口音；
- 基础表达习惯。

固定层只写一次，不随场景重复改写。

角色基准音的示例台词必须继承确认剧本主语言。英文剧本使用角色英文原句或英文中性兜底句，中文剧本使用角色中文原句或中文中性兜底句；不在基准音阶段翻译剧本语言。

## 动态表演层

动态层包括：

- 当前情绪和潜台词；
- 情绪从哪里开始、如何转折、怎样收束；
- 语速、力度、停顿、重音和气息；
- 面对谁、想达到什么目的。

短剧默认使用两档强度：

- `medium`：解释、铺垫、试探、日常对话；
- `high`：争吵、惊恐、爆发、崩溃和强喜剧爆点。

不要只写“愤怒地说”。应写成：

`开始压着火克制质问，听到推脱后怒意迅速上升，最后一句高强度爆发，短句快速推进，核心词加重。`

## 对白、旁白和 OS

- **对白**：明确对象、关系、目的和接话节奏。
- **旁白**：比对白更稳定清楚，负责信息推进，不自动使用播音腔。
- **OS/内心独白**：仍保持角色音色，但距离更近、外放力度更低，更像贴近耳边的内心声音。
- **广告旁白**：写清可信、亲切、专业、煽动或克制的程度，并标出品牌句的落点。

同一角色的三种表达共用同一个音色 Reference。

## 音乐标准

写清四件事：

1. 风格或主要乐器；
2. 情绪作用；
3. 进入、变化和退出位置；
4. 始终压在人声下方，不遮挡台词。

没有明确需要时，不让音乐从头铺到尾。广告、短剧和影视使用音乐推进情绪；纯对白模式禁止音乐。

## 环境音和音效标准

- 环境音负责连续空间，例如车流、车厢、雨声、办公室底噪。
- 音效负责明确事件，例如手机震动、开门、刹车、碰撞、脚步。
- 写清音效发生在什么台词之前、之后或哪个时间点。
- 高动态音效清晰但不过载，不覆盖关键台词。
- 不擅自增加笑声、掌声、转场音、爆炸或口号。

## 原文纪律

- 用户要求忠实配音时，不遗漏、合并、改写或补写台词。
- 动作说明转化为声音事件，但不能把所有视觉动作都强行变成音效。
- 剧本中明确“角色无台词”时，不为其增加声音。
- 时间不足时指出冲突，不通过偷偷删词解决。

## 官方 Reference 的共同语法

- 先逐行定义角色：`角色名是年龄性别，语言或口音，声线特征，声音气质，饰演者为@音频N。`
- 再定义连续声场：音乐的主奏、铺底、情绪和变化；环境声的空间与持续范围。
- 最后按发生顺序写人声和声音事件；音效用“先、随后、紧接着、最后”明确顺序。
- 表演描述要能听见：语速、音量、停顿、重音、气息、笑声、哭腔、距离和空间处理。
- 多角色对话要写清谁先说、谁附和、谁打断，以及音效位于哪句之前、之中或之后。
- 参考音只在角色定义处锁定一次；正文继续使用角色名，避免反复堆叠引用标记。

## 长内容

单段内容接近两分钟时，让提示词保持紧凑，减少重复形容词。超过一段自然完整音频能承载的长度时，按场景或声音连续性拆分，每段重新声明 Reference 映射，避免角色漂移。

## 输出检查

- 开头有全局目标；
- Reference 编号、角色和控制维度明确；
- 固定音色与动态情绪分开；
- 内容顺序与原稿一致；
- 时间、场景、音乐和音效没有互相冲突；
- 结尾有明确约束；
- 提示词中没有配置、路径或实现说明。
