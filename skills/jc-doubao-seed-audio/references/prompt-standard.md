# Seed Audio 提示词标准

一段好的提示词必须回答当前任务真正需要的问题。完整声音轨需要说明生成什么、谁在说、参考谁、怎么说、什么时候说、身处哪里、同时发生什么声音、最后如何结束；无时间戳连续对白只需要角色、参考音、表演和对白顺序。

## 标准顺序

### 1. 全局目标

第一句写清：

- 输出语言或口音；
- 内容类型；
- 目标总时长（仅时间轴或用户明确要求时）；
- 整体风格和表演强度。

示例：

`生成一段约45秒的中文双人悬疑短剧完整声音轨，表演强度高，台词清晰，整体节奏由克制逐渐推向爆发。`

### 2. Reference 锁定

紧接着写每个 Reference 的角色和用途：

`林夏是青年女性、普通话、声线清亮，饰演者为@音频1。周野是中年男性、略带沙哑、说话克制，饰演者为@音频2。`

只参考某个维度时写排除项：

`只参考@音频3的紧张节奏和停顿方式，不参考其音色、语言和背景声。`

### 3. 声场和声音设计

完整声轨才写这一层。说明：

- 室内外和空间距离；
- 环境底声；
- 音乐风格、乐器、情绪和音量关系；
- 必须出现的关键音效；
- 转场时声音怎样变化。

不要只写“加点音乐”“加点音效”。

### 4. 按顺序写内容

每一段使用：

`角色（情绪过程，强度，节奏和动作）：“原文台词。”`

有精确时间时，把时间区间放在它控制的声音之前：

`[2.0s:5.0s] 角色（表演要求）说：“原文台词。”`

时间区间必须是 `[开始秒:结束秒]`，开始小于结束、顺序清楚且不重叠。需要空白时直接写：

`[5.0s:6.0s] 保持安静。`

### 5. 结尾约束

写清最后一个声音事件和禁止增加的内容：

`最后用一记短促低沉的音乐顿点结束，不增加旁白、对白或口号。`

## 角色固定层

角色固定层包括：

- 声音年龄感；
- 声线高低、明暗、厚薄；
- 清亮、温润、低沉、粗粝、沙哑等核心质感；
- 稳定口音；
- 基础表达习惯。

固定层只写一次，不随场景重复改写。

角色基准音的示例台词必须继承确认剧本主语言。英文剧本使用角色英文原句或英文中性兜底句，中文剧本使用角色中文原句或中文中性兜底句；不在基准音阶段翻译剧本语言。

目标约 10 秒的角色基准音，中文朗读正文至少约 35-50 字，英文至少约 22-30 词。优先按原顺序拼接该角色的多句确认台词；仍不足时，补充同语言、同角色身份的中性自然句。时长描述与可朗读文本量必须相符，不能用一条数秒内就会读完的短句充当完整参考音。

## 动态表演层

动态层包括：

- 当前情绪和潜台词；
- 情绪从哪里开始、如何转折、怎样收束；
- 语速、力度、停顿、重音和气息；
- 面对谁、想达到什么目的。

不要把表演压成 low、medium、high 或高中低档位，也不要只写“愤怒地说”。应写成：

`开始压着火克制质问，听到推脱后怒意迅速上升，最后一句高强度爆发，短句快速推进，核心词加重。`

这里的“高强度爆发”是可听见的自然语言结果，不是枚举值；更具体时直接写音量、气息、语速、停顿和重音变化。

## 无时间戳连续对白

- 角色声音特征只使用产品传入的当前角色声音设计。有内容时提取年龄、性别、身份或职业、口音、音高、声线和音色质感；没有内容时不从剧情、参考音文件名或界面标签猜测，只写“角色名饰演者为@音频N”。每个角色独立一行，缺少特征不阻断生成。
- 不写目标总时长、秒数、时间窗或静音区间。
- 按产品给定顺序逐句写角色、面对对象、潜台词和具体表演，再写正式台词。
- 多人按顺序接话，不制造重叠对白；换人处保留自然短停顿，不能用机械等长停顿破坏表演。
- 每句台词前明确说话角色；参考音用于对应角色的声音参考，动态表演由当前台词的导演说明决定。
- 只输出干净对白，不加入音乐、环境声、动作音效、解释或额外台词。

## 对白、旁白和 OS

- **对白**：明确对象、关系、目的和接话节奏。
- **旁白**：比对白更稳定清楚，负责信息推进，不自动使用播音腔。
- **OS/内心独白**：仍保持角色音色，但距离更近、外放力度更低，更像贴近耳边的内心声音。
- **广告旁白**：写清可信、亲切、专业、煽动或克制的程度，并标出品牌句的落点。

同一角色的三种表达共用同一个音色 Reference。

## 音乐标准

写清四件事：

1. 风格或主要乐器；
2. 情绪作用；
3. 进入、变化和退出位置；
4. 始终压在人声下方，不遮挡台词。

没有明确需要时，不让音乐从头铺到尾。广告、短剧和影视使用音乐推进情绪；纯对白模式禁止音乐。

## 环境音和音效标准

- 环境音负责连续空间，例如车流、车厢、雨声、办公室底噪。
- 音效负责明确事件，例如手机震动、开门、刹车、碰撞、脚步。
- 写清音效发生在什么台词之前、之后或哪个时间点。
- 高动态音效清晰但不过载，不覆盖关键台词。
- 不擅自增加笑声、掌声、转场音、爆炸或口号。

## 原文纪律

- 用户要求忠实配音时，不遗漏、合并、改写或补写台词。
- 动作说明转化为声音事件，但不能把所有视觉动作都强行变成音效。
- 剧本中明确“角色无台词”时，不为其增加声音。
- 时间不足时指出冲突，不通过偷偷删词解决。

## 官方 Reference 的共同语法

- 先逐行定义角色：`角色名是年龄性别，语言或口音，声线特征，声音气质，饰演者为@音频N。`
- 再定义连续声场：音乐的主奏、铺底、情绪和变化；环境声的空间与持续范围。
- 最后按发生顺序写人声和声音事件；音效用“先、随后、紧接着、最后”明确顺序。
- 表演描述要能听见：语速、音量、停顿、重音、气息、笑声、哭腔、距离和空间处理。
- 多角色对话要写清谁先说、谁附和、谁打断，以及音效位于哪句之前、之中或之后。
- 参考音只在角色定义处锁定一次；正文继续使用角色名，避免反复堆叠引用标记。

## 长内容

单段内容接近两分钟时，让提示词保持紧凑，减少重复形容词。超过一段自然完整音频能承载的长度时，按场景或声音连续性拆分，每段重新声明 Reference 映射，避免角色漂移。

## 输出检查

- 开头有全局目标；
- Reference 编号、角色和控制维度明确；
- 角色声音参考与动态表演分开；
- 内容顺序与原稿一致；
- 当前模式需要的时间、场景、音乐和音效没有互相冲突；
- 结尾有明确约束；
- 提示词中没有配置、路径或实现说明。
