# 三栏工作区与项目级媒体任务

## 三栏职责

- 左栏：项目阶段和对象导航。
- 中栏：文稿、资产、分镜、图片、视频和成片的唯一成果展示区。
- 右栏：当前对象的修改意见、模型选择和执行按钮，不重复展示成果正文。

Markdown 阅读、编辑、版本切换和媒体预览都应回到中栏完成。右栏按钮始终可见但按条件禁用，不因暂未就绪而从布局中消失。

## 视频反推文稿模式

待实现的“视频反推”作为项目级文稿来源接入现有三栏，不另建窗口：

- 顶部项目、剧集和七阶段保持不变；先新建/选择项目，再选择或新建集。
- 左栏在“文字创作 / 视频反推”之间选择。反推模式只显示“选择本集原片”、“一键反推剧本”和真实进度/错误。
- 中栏复用现有 Markdown 文稿编辑器显示反推剧本；右栏复用现有文稿编辑和确认操作。
- 反推结果确认后才进入项目总监、声音、资产、分镜和成片；不直接跳到 `DubbingSubtitleWorkspace`。
- 项目工作模式在已有正式输入后锁定，防止切换时混用或清空另一条链路的数据。

完整合同见 `docs/tdd/11-视频反推剧本输入路线TDD.md` 和 [[视频反推剧本输入路线]]。

## 项目级任务抽屉

顶部任务图标打开覆盖式窄抽屉，只显示当前项目的资产图、分镜图和视频任务，不改动现有三栏宽度。中栏卡片和任务抽屉读取同一任务记录。

任务状态固定为：

```text
queued -> generating -> downloading -> success
             |              |
           failed         failed
             |              |
           stopped        stopped
```

徽标只统计 `queued`、`generating`、`downloading`，使用低干扰状态色。停止或放弃不能显示为已完成。

## 操作语义

- 停止等待只终止本地等待，不代表上游任务已取消或退款。
- 继续查询复用原 `taskId`；继续下载复用原 `resultUrl`，两者都不能重复付费。
- 重新生成是唯一再次提交付费任务的恢复操作。
- 一个任务失败、停止或被放弃不能锁死整个项目，也不能阻断其他资产或镜头。
- 批量生成拆成独立单项任务，只处理缺失项；已有成功结果或活动任务的目标跳过。
- 任务提交时冻结项目、目标 ID 和输出路径，切换项目后结果仍写回原项目。
