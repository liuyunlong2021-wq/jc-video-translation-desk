# 镜头节奏控制

## 决策

在现有单镜头工作流上增加自动、慢、中、快四档。默认自动。节奏档位决定独立镜头数量，语义结构决定具体切分点。

第一版明确不做 Veo 片内蒙太奇：虽然官方提示指南支持跳切和蒙太奇术语，但高级控制可靠性不稳定，而且片内切镜无法逐镜重试、绑定参考图或精确合成。

## 实施合同

- `ShotPace = 'auto' | 'slow' | 'medium' | 'fast'`。
- 慢、中、快的目标镜头时长分别是 7、4.5、2.5 秒。
- 自动档由 `jc-script-storyboard` 解析为一个固定档位，并通过 `resolvedPace` 回传。
- 客户端使用真实配音时长和最终档位校验镜头数。
- 修改节奏只清空分镜、视频和成片，保留文稿与配音。
- 旧状态没有节奏字段时默认迁移为自动。

完整验收标准见项目 SDD `docs/镜头节奏控制SDD.md`，模型边界见 [[架构/Veo3.1能力边界与镜头节奏]]。
