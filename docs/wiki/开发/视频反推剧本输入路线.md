# 视频反推剧本输入路线

> 状态：TDD-11 已确认，待实施和真实样片验收。

## 已确认设计

「点一点」不新建反推 App 或独立窗口。“文稿”阶段增加项目级来源选择：

```text
文字创作 -> 生成/导入文稿 -> 编辑确认
视频反推 -> 上传本集原片 -> 一键反推 -> 编辑确认
```

两条路线在《确认文稿》合流，后续共用项目总监、Seed Audio / 逐句后配、资产、分镜、分镜图、视频、配音字幕和成片。不增加顶部第八阶段，不跳过文稿确认直接进入配音字幕工作台。

## 执行链

```text
原片 -> ffprobe -> Faster-Whisper 母时间轴
-> gemini-3.6-flash 原生视频分析
-> final-timeline.json
-> 确定性剧本渲染
-> 反推剧本 + 待人工复核
```

- Whisper cue 是对白文字和时间母证据。
- Gemini 只补齐说话人、场次、动作、表情和情绪，不改写有效 cue。
- 只在真实请求限制或样片稳定性需要时按对白间隙切片。
- 不使用 CRV、Qwen、SenseVoice、Sherpa 聚类或三路投票。

## 复用边界

应用内部复用已有 Electron 文件归档、Faster-Whisper、NewAPI Key、Gemini 视频请求、项目/剧集状态、Wiki 和 Markdown 文稿编辑器。打包后不依赖 `~/.agents`、其他仓库或外部 Python 项目。

Codex 版 `jc-fantuishipin` 继续作为独立调用入口；两者共享反推 Schema、短剧格式和固定验收样片，不共享跨仓运行时。

## 数据边界

项目共享输入模式、角色资产和声音设置；每集原片、Whisper、Gemini、反推时间线、草稿和确认文稿按 `episodeId` 隔离。项目产生正式输入后锁定模式，不依靠切换模式清空用户数据。
