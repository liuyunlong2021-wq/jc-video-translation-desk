# AI 原生创作工作流落地

## 已落地范围

2026-07-30，项目完成从旧式简单素材拼接到分段式 AI 原生创作工作流的第一版改造，并在本机构建版中完成最终视频合成人工验收。

主要结果：

- 文稿改为内置 `jc-media-script`，并通过 `gemini-3.6-flash` 执行。
- 分镜提示词先经过 `jc-script-storyboard`，单图提示词再使用 `jc-gpt-image`。
- 声音方案使用项目内 `jc-voice-design`，固定输出文稿和五项声音提示词。
- 用户可上传一个核心参考图；需要主体一致的镜头通过 GPT Image 2 编辑接口生图。
- 视频模型从需要专用转换器的 Seedance 2.0 方案调整为可通过现有接口工作的 Veo 3.1。
- 每张分镜图生成一个连续镜头视频，最终使用统一配音合成。
- 中栏媒体库按参考图、统一配音、分镜图、视频和最终成片分类，以紧凑缩略图展示，点击后弹窗预览。
- 三栏均建立独立可滚动区域，避免窗口高度不足时底部操作不可达。

## 关键技术决策

1. 第一版使用分段确认，不做不可观察的一键全自动流程。
2. 一致性边界收敛为一个核心参考资产，不提前引入完整角色、场景和道具资产系统。
3. 分镜视频必须是单一连续镜头；多镜头卷轴保留给未来真正支持该能力的模型。
4. 视频片段自带声音不进入最终成片，统一配音是唯一音轨。
5. 所有付费任务必须可恢复、可取消，且下载失败不能重复提交生成任务。
