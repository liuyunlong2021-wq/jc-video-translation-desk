# 热缓存

> 2026-08-02 当前架构、实施边界与风险。先读状态，再进入专题页。

## 当前已实施

- 项目已经从单一核心参考图演进为角色、场景、道具资产主导流程；“产品”统一归入道具。
- 资产设计 JSON 是生图正式合同，画风和比例必须进入 JSON；搜索图和用户上传图同属参考图集合。
- Pinterest 使用独立 Electron 浏览器读取真实渲染页，并已完成一次真实 Pin 单图保存验收。
- 当前项目媒体任务抽屉和单项任务控制已实施，设计状态为待真实付费任务验收。
- 导演分镜已具备说话者、声音类型、原文、情绪和时长等时间线基础字段。

## 已确认待执行

- 所有项目逐镜使用 `gemini-3.6-flash` 直读每条原始分镜视频与声音，不抽帧，不再固定截取每段前 N 秒。
- 唯一剪辑合同为 `editing-timeline.json`，由 `ffprobe` 校验、FFmpeg 确定性执行。
- 单讲述者复用 `jc-voice-design`；多角色或画面内对白使用 IndexTTS2 多情绪包。
- 原声策略为保留原声、配音并保留环境声、仅使用配音；人声分离只在确有待替换人声时执行。
- 字幕属于成片自动产物。顶部七阶段为：文稿、资产、分镜、分镜图、视频、配音、成片。

## 当前风险

- Gemini 逐镜智能剪辑、IndexTTS2 正式配音、条件人声分离、混音和字幕新链路尚未完整实现和验收。
- Pinterest 浏览器链路仍需在正式打包 App 中按项目工作流复验。
- 媒体任务停止、恢复查询、恢复下载和局部失败仍需真实付费任务验收。
- 当前工作区有未提交代码与 SDD 变更；不能仅凭设计文档声明功能完成。
