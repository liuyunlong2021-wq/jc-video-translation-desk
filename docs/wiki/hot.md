# 热缓存

> 2026-07-30 当前最需要优先读取的结论与入口。

## 当前稳定结论

- 分段式 AI 短视频闭环已经跑通：文稿确认 -> 声音设计 -> 配音 -> 分镜图 -> 分镜视频 -> FFmpeg 合成。
- 固定模型为 `gemini-3.6-flash`、`gpt-image-2`、`veo-3.1-generate-preview`、`rh-aiapp-voice-design`。
- 最终成片以统一配音的真实时长为准，丢弃各视频片段原声，不把不同片段的声音混入成片。
- 素材保存在 Electron `userData/media-runs/<runId>/`，重新打开应用可恢复最近任务，不需要绑定用户自选文件夹。
- 2026-07-30 已人工完成一次最终视频合成；实现已提交并推送到 `main`，Git 提交为 `57c48b6`。
- 镜头节奏采用自动、慢、中、快四档；保持一图一条 Veo 独立镜头，不启用片内蒙太奇。详见 [[架构/Veo3.1能力边界与镜头节奏]]。
- 镜头节奏和创作参数实现已通过 39 项自动测试、类型检查和未签名通用应用打包。
- 创作参数与品牌视觉升级已实施：9 个具体风格预设、5–180 秒目标时长、赚钱短片品牌和绿色主操作主题。

## 当前风险

- 正式签名构建仍受本机钥匙串 `errSecInternalComponent` 影响；未签名本地包可正常生成，验证状态见 [[巡检报告/2026-07-30验证状态]]。
- 开发和打包不要并发写入 `dist-electron/`。构建前清理只能降低陈旧产物风险，不能修复仍在运行的旧 Electron 进程。详见 [[排障/构建产物与运行进程版本不一致]]。
