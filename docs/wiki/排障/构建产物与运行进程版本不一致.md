# 构建产物与运行进程版本不一致

> 历史排障记录：本页保留 2026-07-30 当时的应用名和 `userData/media-runs` 路径作为原始证据。现行应用名、项目位置和启动方式以 [[../运维/本地构建与发布]] 为准。

## 现象

点击“合成视频”时报错：

```text
Cannot find module './FlacParser-DV2lDPo3.js'
Require stack: dist-electron/main-DRU1A3Sd.js -> dist-electron/main.js
```

错误发生在加载 `music-metadata` 的 FLAC 动态分块时，不代表 API、配音文件或视频素材损坏。

## 已确认根因

旧 Electron 进程仍从已经卸载的 `/Volumes/短视频工厂 1.2.2-universal/` 安装包运行，并引用旧版 `main-DRU1A3Sd.js`。项目当前 `dist-electron/` 已经是另一组构建产物：`main-D34edPBD.js` 引用 `FlacParser-BagHiyRX.js`。

主入口和动态分块来自两次不同构建，因此旧进程请求了已不存在的哈希文件。根因是运行进程与构建产物版本不一致，不是媒体生成渠道失败。

## 已验证处理

1. 精确识别并结束旧安装包路径下的短视频工厂进程，不影响其他 Vite/Electron 项目。
2. 从当前项目的 `release/1.2.2/mac-universal/赚钱短片.app` 重新启动。
3. 按当时的存储架构，不删除 `userData/media-runs/`，不重新生成已有素材。
4. 再次点击合成，最终视频成功生成。

## 预防规则

- 不要让开发服务和打包任务同时写 `dist-electron/`。
- `pnpm build` 前由 `prebuild` 清理 `dist/`、`dist-electron/` 和当前版本 `release/`，避免陈旧哈希分块混入新包。
- 构建结束后必须完全退出旧 Electron 进程，再打开新包。
- 遇到 `Cannot find module './<动态分块>-<hash>.js'` 时，先比对运行进程路径和 `dist-electron/main*.js` 的引用，不要先重做付费媒体任务。

运行规则见 [[运维/本地构建与发布]]，验证结论见 [[巡检报告/2026-07-30验证状态]]。
