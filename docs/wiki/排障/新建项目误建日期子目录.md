# 新建项目误建日期子目录

## 现象

用户在“新建项目”中选择或创建“功夫女友”文件夹后，应用又在其中创建“新项目-YYYYMMDD”子目录，界面项目名也变成日期名。

## 根因

`electron/media-workspace.ts` 的新建入口使用 `showSaveDialog()`。macOS 保存对话框会把用户选中的文件夹解释为父目录，再把默认的“新项目-日期”解释为最终目录名。代码随后取最终目录 basename 作为显示名，因此产生了双层目录和错误项目名。

## 修复

- 新建入口改用 `showOpenDialog({ properties: ['openDirectory', 'createDirectory'] })`。
- 用户选中的空文件夹本身直接成为项目根，文件夹 basename 是初始项目显示名。
- 已含 `project.json` 的目录引导用户使用“打开已有项目目录”；其他非空目录拒绝初始化。
- 初始化用户原有空目录失败时，只清理本次生成的项目内容，不删除用户选中的根目录。
