# AI 媒体工作流可复用经验

## 1. 项目是唯一边界

Wiki、结构化状态、媒体和任务必须跟随项目。异步任务提交时冻结项目和目标 ID，不能在完成回调里重新读取当前选中的项目。

## 2. Markdown 与执行状态各司其职

Markdown 适合阅读、编辑、审批和双链；结构化状态、稳定 ID 和媒体路径负责执行。不要让 Markdown 文案或数组下标承担资产绑定。

## 3. 先建立资产，再绑定分镜

角色、场景、道具先由各自 Skill 生成正式设计 JSON，再选择是否搜索或上传参考图，最后生成资产图。导演分镜绑定稳定资产 ID，避免后补资产时全流程失效。

## 4. 参考图是可选增强

搜索图和用户上传图是同一种输入。参考图存在时按资产类型限制参考范围，项目画风、比例和主体要求仍服从设计 JSON；没有参考图也必须能够生成。

## 5. 批量动作必须增量执行

批量按钮只扫描未完成项。已有结果不能阻止新增资产、补图或局部重试；单项失败也不能锁住项目。

## 6. 付费生成与结果恢复分离

生成、查询和下载是三个不同动作。继续查询和继续下载复用原任务，不得重复付费；只有“重新生成”才提交新任务。停止本地等待不等于取消云端计费。

## 7. 成果和操作不要混栏

中栏是文稿、资产、图片、视频和成片的唯一展示区；右栏只放修改意见与执行按钮。任务总览使用覆盖式项目抽屉，不复制第二套媒体状态。

## 8. 视频不能固定截前几秒

生成模型的动作和说话可能延迟出现。应让多模态模型结合分镜脚本逐镜提出裁切区间，再由程序校验时长、FFmpeg 确定性执行。无法判断时保留整镜，比猜时间点更可靠。

## 9. 声音处理应按素材选择

保留原声、替换人声并保留环境声、完全替换原音是三种不同策略。人声分离只在第二种且素材确有目标人声时运行，不应成为所有项目的固定成本。

## 10. 字幕共享最终时间轴

字幕文字来自确认分镜原文，时间来自最终剪辑和配音，不应再通过 ASR 猜回已经掌握的文本。字幕属于成片合成，不必增加独立产品阶段。
