# 资产提示词与 Pinterest 参考图链路

## 结论

联网找图是资产生成前的可选增强，不是生成资产图的前置条件。现行顺序固定为：

```text
资产 Skill 生成完整设计 JSON
  -> 从 JSON 提取专业搜索词
  -> Pinterest 渲染搜索页
  -> 按页面顺序进入第一个可用 Pin
  -> gallery-dl 下载或浏览器元素截图
  -> 写入当前资产参考图集合
  -> 用户决定是否生成资产图
```

模型不参与搜图、选图和下载。Pinterest 私有 HTTP 接口、Bing 和 Wikimedia 不作为静默备用源。

## 搜索词规则

搜索词来自完整资产 JSON，但不是把整份 JSON 塞进搜索框。查询由题材或媒介、资产类型、关键特征和影视制作构图组成：

- 角色：真人优先电影定妆照、全身角色海报；动画优先角色设定图或定妆海报。
- 场景：优先电影或动画场景，全景、建立镜头和清晰空间关系是硬约束。
- 道具：优先电影道具特写、产品级道具参考或动画道具设定图。

搜索词既不能退化成单个泛词，也不需要堆叠无效长句。资产身份和关键特征负责“搜什么”，影视制作词负责“要什么构图”。

## 浏览器与下载

- 使用独立、沙箱化的 Electron 浏览器窗口读取已渲染 DOM。
- 按页面顺序选择第一个合法且未被排除的 Pin，不建立候选评分系统。
- 优先下载 Pin 原图；不可用时只截取主图元素，不截浏览器导航、按钮或推荐区。
- 登录或验证留在专用窗口处理；成功、取消或失败后应关闭窗口，不能在桌面持续闪烁或残留。
- 输出只能写入当前项目、当前 `assetId` 的受控目录。

## 用户交互

右栏保留三个阶段按钮：生成资产提示词、搜索下载参考图、生成资产图。用户也可以直接上传参考图；搜索图与上传图同等参与生图。

已有参考图的资产默认跳过搜索。用户删除不满意版本后，再次点击搜索只补空缺项；删除过的 Pin 应加入当前资产排除集合，避免原图立即回来。单项搜索失败不能阻止其他资产，也不能阻止无参考图生图。
