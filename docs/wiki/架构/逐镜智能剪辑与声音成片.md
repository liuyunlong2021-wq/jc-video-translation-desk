# 逐镜智能剪辑与声音成片

> 状态：方案已确认，待按 SDD 完整执行和验收。不要把本页写成现有生产能力。

## 唯一新流程

```text
导演分镜和分镜视频
  -> gemini-3.6-flash 结合对应分镜脚本逐镜直读原始视频与声音
  -> 每镜输出关键动作、说话窗口和建议裁切区间
  -> 合并并校验 editing-timeline.json
  -> FFmpeg 确定性裁切并拼接 picture-master.mp4
  -> 按声音策略生成或保留声音
  -> 依同一时间轴混音并生成字幕
  -> 烧录字幕，输出成片
```

所有项目都逐镜分析，包括单讲述者项目。不能再固定截取每条视频前 N 秒，因为模型动作或说话可能延迟出现。Gemini 不读取拼接后的长母带；每条 4 / 6 / 8 秒原始视频一旦就绪即可直接提交，不抽帧，避免长上下文后段注意力下降。

## 剪辑合同

`editing-timeline.json` 是唯一剪辑合同。Gemini 只给建议，`ffprobe` 校验源文件真实时长，FFmpeg 才是唯一执行器。模型无法可靠判断时保留整镜并标记人工检查，不猜裁切点。

导演分镜必须给每镜记录：稳定 `shotId`、声音类型、说话者、确认原文、情绪和时长预算。声音类型固定为：

- `onscreen`：画面内角色说话；一个镜头只允许一个连续说话轮次。
- `voiceover`：旁白或画外音，视频模型不生成旁白人声。
- `none`：无对白动作镜头，不创建配音任务。

## 声音策略

成片只允许三种互斥策略：

| 策略 | 行为 |
|---|---|
| 保留原声 | 保留裁切后的原音，不生成正式配音 |
| 配音并保留环境声 | 替换目标人声，同时保留环境声或背景声 |
| 仅使用配音 | 丢弃原音，只混入正式配音 |

人声分离是条件能力，不是固定步骤。只有选择“配音并保留环境声”，且原素材确有待替换人声时才运行。纯旁白项目若原视频没有人声，可直接保留环境声并混入旁白。

单讲述者继续使用现有 `jc-voice-design`。多角色或画面内对白使用角色绑定的 IndexTTS2 多情绪包；视觉资产 `entityId` 同时作为 `speakerId`，每集只选择情绪样音，不重新设计角色音色。

## 字幕与 UI

字幕文字来自确认分镜原文，时间来自剪辑时间轴和最终配音时长，不依赖 ASR 反推文案。字幕属于成片的自动产物，不新增顶部阶段。

顶部七阶段固定为：`文稿 → 资产 → 分镜 → 分镜图 → 视频 → 配音 → 成片`。中栏五视图为：`文稿 | 资产/声音 | 分镜 | 分镜图/视频 | 成片`。完整实施合同见 `docs/导演分镜时间轴与角色配音编排SDD.md`。
