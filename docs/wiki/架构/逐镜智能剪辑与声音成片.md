# 逐镜智能剪辑与声音成片

> 状态：TDD-00 至 TDD-05 已完成共享合同、项目总监、声音绑定、素材 SRT、Gemini 时间轴和配音字幕工作台骨架；真实后期动作待实现和端到端验收。

## 总体边界

项目总监必须在声音生成、资产和分镜之前确认制作路线。路线只允许：

- `narration-promo`：旁白宣传片，以正式旁白时间轴为第一时间轴。
- `drama`：剧情片，以确认剧本、角色身份和导演分镜为第一依据。

用户可以修改项目总监的路线判断；下游只读取已确认 `ProjectDirectorPlan.productionRoute`，存在待确认稿时路线派生值为 `null`。路线确认前先写入 `wiki/项目/项目总监.md` 与 `wiki/项目/制作路线.md`，再开放下游。顶部七阶段固定为：

```text
文稿 -> 资产 -> 分镜 -> 分镜图 -> 视频 -> 配音字幕 -> 成片
```

“配音字幕”是正式工作台，不再增加独立字幕阶段。

## 两条制作路线

### 旁白宣传片

```text
项目总监确认 narration-promo
  -> 用户选择设计声音或克隆音色包，生成正式旁白
  -> Faster-Whisper 自动生成 narration-timeline.json 和旁白 SRT
  -> 宣传片导演按旁白时间轴、镜头节奏和视觉总纲设计画面
  -> Veo 或 Grok 生成分镜图和视频
  -> 每条素材生成 SRT
  -> Gemini 逐条读取原视频、确认文稿、完整分镜提示词和素材 SRT
  -> editing-timeline.json
  -> 工作台微调剪辑点并校对字幕
  -> 混入正式旁白、环境声和动作音
  -> 烧录配音和字幕，输出成片
```

旁白时间轴在正式旁白生成后自动运行，不增加“生成旁白时间轴”按钮。宣传片默认要求视频模型不生成人声，因此默认不做人声分离；素材意外出现人声时才按需启用。

### 剧情片

```text
项目总监确认 drama
  -> 生成角色、场景和道具资产
  -> 为有台词角色绑定稳定 speakerId 和音色包
  -> Veo 或 Grok 导演路线生成分镜、分镜图和带原声视频
  -> Faster-Whisper 为每条素材生成 SRT
  -> Gemini 逐条读取原视频、确认剧本、完整分镜提示词和素材 SRT
  -> 通过台词与剧本直接确定 speakerId，通过画面确定动作和剪辑点
  -> editing-timeline.json
  -> 用户生成中文配音，按需翻译并生成英语配音
  -> 按需分离并去除原人声，混回背景声、环境声和动作音
  -> 烧录配音和字幕，输出成片
```

资产阶段只绑定角色音色，不预创建逐句任务或空 WAV。`editing-timeline.json` 就绪后只开放“生成中文配音”，用户点击后 IndexTTS2 才按当前时间窗生成逐句配音。

## 真实剪辑证据链

```text
生成 SRT
  -> Faster-Whisper 识别人声文字与精确 start/end

生成剪辑时间轴
  -> gemini-3.6-flash 读取原视频 + 确认剧本/文稿 + 完整分镜提示词 + 素材 SRT
  -> 对白：通过台词匹配直接确定 speakerId
  -> 无对白：通过画面确认戏剧动作和真实区间
  -> editing-timeline.json

执行
  -> ffprobe 校验真实媒体时长
  -> FFmpeg 只执行当前采用的剪辑点
```

不再使用 Sherpa 说话人聚类，不生成 `spk0/spk1`、说话人 SRT 或 `speakerMap`。Sherpa-ONNX 只作为 Spleeter 人声分离链路的推理依赖。Whisper 识别文字只提供时间证据；正式字幕文字始终来自确认文稿或剧本。

`editing-timeline.json` 保存 Gemini 原始区间和当前采用区间。工作台选中一行后，用右栏双端滑块逐条微调；松手即自动持久化，不设入点、出点、保存或确认按钮。FFmpeg 不截取前 N 秒，也不自行扩张、缩短或猜测区间。

## 配音字幕工作台

中栏播放尚未物理裁切的原始视频，并显示六列表格。横屏、竖屏统一采用左侧预览/右侧表格；进入配音字幕阶段自动收起左侧项目设置，左右栏均可从顶部切换，两栏收起即为最大空间模式。表格独立滚动，预览与吸顶表头保持可见；点击素材行后从当前采用剪辑点的起点播放，并在终点暂停。

```text
时间轴 | 视频片段预览 | 角色 | 配音试听 | 中文字幕 | 英文字幕
```

右栏只保留这些实际操作：

```text
生成 SRT
生成剪辑时间轴
重选剪辑点（当前行双端滑块）
生成中文配音
翻译所有字幕
生成英语配音
分离原人声和背景声
去除原人声
混回背景声、环境声和动作音
烧录配音和字幕
```

中文字幕可直接编辑并自动持久化，没有保存按钮。英文字幕初始为空；“翻译所有字幕”使用用户当前选择的 `textModel`。烧录按钮就是生成成片，不再增加最终时间轴确认、最终混音试听或独立导出按钮。

## 能力与事实源

| 环节 | 能力 | 事实源 |
|---|---|---|
| 素材转录 | Faster-Whisper Large V3 Turbo | 每素材 Whisper JSON 与 SRT |
| 逐镜理解 | `gemini-3.6-flash` 直读视频，不抽帧 | `editing-timeline.json` |
| 角色身份 | SRT 台词 + 确认剧本直接匹配 `speakerId` | 确认剧本、分镜提示词、时间轴 |
| 中文/英文配音 | IndexTTS2 多情绪角色包 | 角色声音 Wiki、逐句 WAV、对白资产索引 |
| 设计声音 | Qwen3-TTS VoiceDesign 或现有云端声音设计 | 角色声音设定与音色包 |
| 人声分离 | Sherpa-ONNX + Spleeter ONNX | `vocal.wav`、`instrument.wav`、音频处理记录 |
| 裁切、混音、烧录 | ffprobe + FFmpeg | 当前采用剪辑点、最终音轨和成片 |

`rh-grok-image-video` 已真实验证九宫格分镜板、多图参考、人类与动物角色一致性和片内切镜。官方能力合同为 `6-30` 秒；未逐档实测的时长不写成已验证。Veo 继续使用一镜一图、一镜一视频的 `4/6/8` 秒路线。

TDD-04 已实现明确的“生成剪辑时间轴”动作。同一物理视频只提交一次，Grok 多镜携带全部完整分镜；Gemini 同时读取确认剧本、Whisper JSON/SRT 和原视频。程序校验区间、cue、角色与对白窗口，失败或不可靠结果保留完整素材并要求复核，随后立即写入唯一 `editing-timeline.json`。模拟 API 合同、聚合、持久化和 FFmpeg 尚未运行的独立落盘已测试；真实付费 Gemini 尚未验收。
