# 逐镜智能剪辑与声音成片

> 状态：TDD-00 至 TDD-07 与 TDD-10 原代码主链已完成；TDD-11 视频反推输入路线待执行；可编辑豆包语音稿、Seed Audio 官方请求和真实完整项目端到端验收待执行。

## 总体边界

项目总监必须在声音生成、资产和分镜之前确认内容类型；声音制作路线由用户人工选择。内容类型只影响导演语义，声音制作路线决定时间轴先后和最终音轨采用策略。

内容类型只允许：

- `narration-promo`：旁白宣传片，以正式旁白时间轴为第一时间轴。
- `drama`：剧情片，以确认剧本、角色身份和导演分镜为第一依据。

用户可以修改项目总监的内容类型判断；`AudioProductionRoute` 默认是 `seed-full-track`，用户明确选择后才改为 `post-dub`：

- `seed-full-track`：Seed Audio 先生成完整声音轨和真实声音时间轴，再写分镜；
- `post-dub`：保持现有先生成视频、后使用 IndexTTS2/Qwen3-TTS 逐句后配的流程。

下游只有在内容类型和声音路线都确认后才开放。路线确认前先写入 `wiki/项目/项目总监.md` 与 `wiki/项目/制作路线.md`，再开放下游。顶部七阶段固定为：

```text
文稿 -> 资产 -> 分镜 -> 分镜图 -> 视频 -> 配音字幕 -> 成片
```

“配音字幕”是视频生成后的正式后期工作台；Seed 路线在资产之后增加前置“全局配音”视图，不另建第二套 Store 或字幕阶段。

## 两种项目输入模式

现有文字创作和待实现的视频反推共用同一个 Electron 应用、项目/剧集边界和下游生产链：

```text
文字创作：输入需求 / 导入 Markdown -> 编辑并确认文稿
视频反推：上传本集原片 -> Whisper/Gemini -> 编辑并确认文稿
                                           |
                                           v
                         项目总监 -> 资产 -> 全局配音（Seed） -> 分镜 -> 成片
```

工作模式属于项目，所有剧集继承；原片、Whisper/Gemini 证据、反推时间线和文稿按 `episodeId` 隔离。两条路线只在《确认文稿》合流，视频反推不跳过文稿确认直接进入配音字幕工作台。已有正式输入后不允许通过切换模式清空数据，需要另一条链路时新建项目。完整合同见 [[开发/视频反推剧本输入路线]]。

## 两条制作路线

### 豆包整段声音轨路线（旁白与有对白内容）

```text
默认使用 seed-full-track
  -> 项目总监确认内容类型、角色、场景、道具和导演资料
  -> 视觉资产生成并确认
  -> 全局配音工作台逐角色选择/绑定已有参考音
  -> 按角色 JSON 生成音色提示词
  -> 按已保存提示词生成 Seed 角色参考音并绑定产品 voiceProfileId
  -> 整段配音安排确定角色分组、参考音顺序和任务边界
  -> 生成全局声音提示词
  -> jc-doubao-seed-audio 生成可编辑的豆包语音稿
  -> 用户查看或修改语音稿
  -> Seed Audio 按当前语音稿生成对白/旁白/音乐/环境声/动作音效完整声音轨
  -> Faster-Whisper 自动生成真实声音时间轴和 SRT
  -> 导演按声音时间轴、镜头节奏和视觉总纲设计画面
  -> Veo 或 Grok 按原分镜提示词正常生成画面及其原生声音
  -> 每条素材生成 SRT
  -> Gemini 逐条读取原视频、确认文稿、完整分镜提示词和素材 SRT
  -> editing-timeline.json
  -> 工作台微调剪辑点并校对字幕
  -> 按 Seed 路线采用完整声音轨；视频原生声音保留为证据或备用
  -> 烧录配音和字幕，输出成片
```

`确认文稿.md`、`整段配音安排.json` 和 `声音导演稿.md` 分别是内容事实、程序任务和 Seed 提示词事实源，不能互相覆盖。声音时间轴在 Seed 完整声音轨生成后自动运行，不增加独立时间轴按钮。VEO/Grok 不被禁止生成原生声音；是否使用视频原生声音只由后期声音路线和采用策略决定。

### 逐句后配路线（剧情内容示例）

```text
用户人工选择 post-dub
  -> 项目总监确认内容类型、角色、场景、道具和导演资料
  -> 生成角色、场景和道具资产
  -> 为有台词角色绑定稳定 speakerId 和音色包
  -> Veo 或 Grok 导演路线生成分镜、分镜图和原生声音视频
  -> Faster-Whisper 为每条素材生成 SRT
  -> Gemini 逐条读取原视频、确认剧本、完整分镜提示词和素材 SRT
  -> 通过台词与剧本直接确定 speakerId，通过画面确定动作和剪辑点
  -> editing-timeline.json
  -> 用户生成中文配音，按需翻译并生成英语配音
  -> 按需分离并去除原人声，混回背景声、环境声和动作音
  -> 烧录配音和字幕，输出成片
```

资产阶段只绑定角色音色，不预创建逐句任务或空 WAV。`editing-timeline.json` 就绪后只开放“生成中文配音”，用户点击后 IndexTTS2 才按当前时间窗生成逐句配音。

## 真实剪辑证据链

```text
Seed 声音时间轴
  -> Seed 完整声音轨落盘
  -> Faster-Whisper 识别人声文字与精确 start/end

素材 SRT
  -> 视频素材落盘
  -> Faster-Whisper 识别人声文字与精确 start/end

生成剪辑时间轴
  -> gemini-3.6-flash 读取原视频 + 确认剧本/文稿 + 完整分镜提示词 + 素材 SRT
  -> 对白：通过台词匹配直接确定 speakerId
  -> 无对白：通过画面确认戏剧动作和真实区间
  -> editing-timeline.json

执行
  -> ffprobe 校验真实媒体时长
  -> FFmpeg 只执行当前采用的剪辑点
```

不再使用 Sherpa 说话人聚类，不生成 `spk0/spk1`、说话人 SRT 或 `speakerMap`。Sherpa-ONNX 只作为 Spleeter 人声分离链路的推理依赖。Whisper 识别文字只提供时间证据；正式字幕文字始终来自确认文稿或剧本。

`editing-timeline.json` 保存 Gemini 原始区间和当前采用区间。工作台选中一行后，用右栏双端滑块逐条微调；松手即自动持久化，不设入点、出点、保存或确认按钮。FFmpeg 不截取前 N 秒，也不自行扩张、缩短或猜测区间。

## 配音字幕工作台

中栏播放尚未物理裁切的原始视频，并显示六列表格。横屏、竖屏统一采用左侧预览/右侧表格；进入配音字幕阶段自动收起左侧项目设置，左右栏均可从顶部切换，两栏收起即为最大空间模式。表格独立滚动，预览与吸顶表头保持可见；点击素材行后从当前采用剪辑点的起点播放，并在终点暂停。

```text
时间轴 | 视频片段预览 | 角色 | 配音试听 | 中文字幕 | 英文字幕
```

右栏只保留这些实际操作：

```text
生成 SRT
生成剪辑时间轴
重选剪辑点（当前行双端滑块）
生成中文配音
翻译所有字幕
生成英语配音
分离原人声和背景声
去除原人声
混回背景声、环境声和动作音
烧录配音和字幕
```

中文字幕可直接编辑并自动持久化，没有保存按钮。英文字幕初始为空；“翻译所有字幕”使用用户当前选择的 `textModel`。烧录按钮就是生成成片，不再增加最终时间轴确认、最终混音试听或独立导出按钮。

## 能力与事实源

| 环节 | 能力 | 事实源 |
|---|---|---|
| 素材转录 | Faster-Whisper Large V3 Turbo | 每素材 Whisper JSON 与 SRT |
| 逐镜理解 | `gemini-3.6-flash` 直读视频，不抽帧 | `editing-timeline.json` |
| 角色身份 | SRT 台词 + 确认剧本直接匹配 `speakerId` | 确认剧本、分镜提示词、时间轴 |
| 声音路线 | 用户人工选择 `seed-full-track` 或 `post-dub` | 项目制作路线 Wiki |
| 声音导演稿 | `jc-doubao-seed-audio` 编译，用户可编辑 | `声音导演稿.md` |
| 整段配音 | Seed Audio 生成角色基准音和对白/旁白/音乐/环境声/动作音效完整声音轨 | Seed 声音 Wiki、声音时间轴和生成记录 |
| 逐句配音 | Qwen3-TTS/IndexTTS2 保持现有逐句中英文后配路线 | 角色声音 Wiki、逐句 WAV、对白资产索引 |
| 人声分离 | Sherpa-ONNX + Spleeter ONNX | `vocal.wav`、`instrument.wav`、音频处理记录 |
| 裁切、混音、烧录 | ffprobe + FFmpeg | 当前采用剪辑点、最终音轨和成片 |

`rh-grok-image-video` 已真实验证九宫格分镜板、多图参考、人类与动物角色一致性和片内切镜。官方能力合同为 `6-30` 秒；未逐档实测的时长不写成已验证。Veo 继续使用一镜一图、一镜一视频的 `4/6/8` 秒路线。

每集以 `wiki/制作/episode-001.md` 作为双链索引，连接项目总监、确认文稿、声音绑定、分镜、素材 SRT、剪辑时间轴、配音、音频处理、字幕和成片。核心产物为：
