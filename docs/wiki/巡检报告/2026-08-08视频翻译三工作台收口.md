# 视频翻译三工作台收口巡检

> 状态：代码修复完成，真实样片验收待执行
>
> 记录时间：2026-08-08 CST

## 已确认主链

现行流程固定为：字幕工作台完成 `压缩 -> 固定 10 秒切片 -> Gemini 3.6 Flash 逐片扒片 -> 程序合并 -> 人工确认最终时间戳剧本`；配音工作台只基于该最终剧本、实际发言角色和已确认参考音生成录音棚配音；成片工作台再生成人工配音对白时间戳、剪句、分离原片人声并合成。

主流程本身不需要增加 Whisper、智能切片、全片互审或额外模型裁决。当前复杂度主要来自同一事实被前端状态、Markdown、manifest 和 index 重复保存。

## 本轮必须修复

### 字幕工作台

- 角色绑定变化必须使旧译文失效；只改时间边界不得清空全集译文。
- 未知说话人不得因共同占位名“新角色”被批量合并。
- 人工新增对白必须允许真实重叠；翻译按钮门禁必须与后端输入校验一致。
- 扒片检查点必须绑定切片、角色与合同版本；最终确认必须校验视频时长边界。

### 配音工作台

- 所有显示、门禁与批量生成只处理最终剧本中实际发言角色。
- 全局提示词按对白行顺序校验，重复短句不得误判。
- 人工修改提示词必须使旧配音版本、配音时间戳、混音与成片失效。
- 确认角色声音时必须验证 `voiceProfileId` 与参考音文件真实可用。
- `screenshotId` 必须从字幕角色记录贯通到持久化和配音输入；无法提供真实截图 ID 时不得伪造。

### 成片工作台

- 主进程以最终剧本和配音版本 manifest 为权威输入，renderer 只传稳定 ID。
- 所有进入输出路径的语言、块 ID、cue ID 必须先做安全校验。
- 时间戳切片检查点必须在单块完整校验后落盘；缺失或重复 cue 会清除受影响块检查点，下一次点击生成新版本。
- 逐句混音固定关闭 `amix` 默认归一化，防止对白数量增加导致音量衰减。
- 成片记录必须保存最终剧本、配音版本和配音时间戳的 ID/hash。

## 确认删除或收缩

- 保留字幕 UI 仍使用的复核字段；删除来源上下文独立 IPC 链和不再参与当前合同的旧路径镜像。
- 删除只写不读的翻译状态路径与旧 Whisper 持久化字段。
- 配音块计划只返回 arrangement，不生成随后必被覆盖的空提示词。
- 配音版本 manifest 作为权威记录；index 只保留列表摘要，不复制完整版本对象。
- 删除版本对象中可由 blocks 推导或从未消费的重复字段。
- 删除 `jc-luyinpeng` 中与强制输出标准逐项重复的末尾检查表。

## 暂不机械删除

- 旧项目迁移逻辑只有在确认不再需要读取旧序列化数据后才删除。
- 块级 Seed Audio 中间文件去重涉及现有通用创作路线，必须只收缩视频翻译专用调用，不能影响非翻译项目。
- `screenshotId` 没有可靠来源时保持可选并标记缺失，不通过随机 ID 冒充真实截图资产。

## 修复结果

- 字幕：角色改绑会使译文失效；时间边界单独失效；人工新增对白允许重叠；未知占位角色不再批量合并；确认校验包含视频时长；扒片检查点绑定切片、角色和合同版本。
- 配音：显示、门禁和批量生成统一按本集实际发言角色过滤；提示词按对白行顺序逐条校验；编辑全局提示词会清理旧配音及下游状态；角色声音确认会验证真实 `voiceProfileId` 和参考音文件；现有 `screenshotId` 会写入角色档案并传入声音设计输入。
- 成片：时间戳主进程读取最终剧本 JSON 与配音 manifest，不消费 renderer 回传的整份剧本；语言、块 ID、cue ID 先安全校验；坏时间戳检查点会被清除；混音使用 `normalize=0`；成片写入 `finalVideoVersionId`、剧本/配音/时间戳 ID 与 hash。
- 冗余：删除来源上下文 IPC、只写路径状态、配音计划空提示词、版本重复字段、单调用包装和 Skill 重复检查表；旧项目迁移兼容与通用创作路线字段保留，避免误伤历史数据。
- 文档合同：配音失败版本不进入可用索引，再次点击创建新 `voiceVersionId`，与代码行为一致。
