# TDD-01：项目总监与制作路线

> 日期：2026-08-03
> 状态：已完成并验证
> 上位设计：`docs/导演分镜时间轴与角色配音编排SDD.md`
> 前置依赖：`docs/tdd/00-共享生产合同与状态机TDD.md`

## 1. 目标

文稿确认后，项目总监必须判断本项目走 `narration-promo` 或 `drama`，说明原因，并允许用户在确认前修改。下游只读取已经确认的项目总监方案，不另存一份可能漂移的路线状态。

## 2. 本轮范围

1. `jc-film-style` 的 APP 运行时 JSON 增加 `productionRoute` 和 `routeReason`。
2. 项目总监解析器严格校验两条合法路线和非空理由。
3. 项目总监页显示 `旁白宣传片 | 剧情片` 两段式控件；切换已确认路线时只创建待确认稿，不立即删除数据。
4. Store 从已确认方案派生当前制作路线；有待确认稿时关闭下游门禁。
5. 确认方案时保留仍在项目总监资产白名单中的既有资产版本，清除路线相关下游。
6. 确认成功前依次写入 `wiki/项目/项目总监.md`、`wiki/项目/制作路线.md` 和资产页面。

## 3. 明确不做

- 不生成宣传片旁白，不接 Qwen3-TTS 或 IndexTTS2。
- 不接 Faster-Whisper、Gemini 剪辑时间轴或配音字幕工作台。
- 不增加新的顶部阶段、弹窗、路线设置页或独立路线 Store 字段。
- 不为未发布旧项目补复杂迁移；无合法路线的旧项目视为项目总监未确认。

## 4. 数据合同

复用 TDD-00 的唯一类型：

```ts
type ProductionRoute = 'narration-promo' | 'drama'
```

`ProjectDirectorDraft` 和 `ProjectDirectorPlan` 增加：

```ts
productionRoute: ProductionRoute
routeReason: string
```

判定规则：

- 统一旁白、解说、产品介绍、知识讲述或广告口播推动全片：`narration-promo`。
- 角色行动、对白、冲突和场景表演推动故事：`drama`。
- 项目中存在角色不等于剧情片；判断依据是叙事驱动力。
- 下游只能读取 `confirmedProductionRoute`；没有确认方案或存在待确认稿时返回 `null`。

## 5. 用户交互

项目总监中栏顶部固定显示：

```text
制作路线  [旁白宣传片 | 剧情片]
判断理由  ……
```

- AI 草稿生成后，用户可直接切换并确认。
- 已确认方案切换路线后转为待确认稿，右栏主按钮变为“确认项目总监方案”。
- 切换动作本身不失效资产、声音、分镜或媒体；确认时才执行失效。
- 路线控件不放进全局设置，也不增加额外保存按钮。

## 6. Wiki 合同

确认成功后至少存在：

```text
wiki/项目/项目总监.md
wiki/项目/制作路线.md
```

两页互相双链。`制作路线.md` 保存路线代码、中文名称、判断理由和“用户可在项目总监页修改”的事实。必须先完成 Wiki 写入，再把确认方案暴露给 Store。

## 7. 失效与保留

确认新方案时复用现有项目总监失效入口：清除路线专属声音、分镜、视频、剪辑和成片；保留确认文稿。资产以新项目总监 ID 白名单为准，同类型同名称实体沿用既有 ID、设计和媒体版本，新实体才创建新 ID。

## 8. 测试先行清单

1. 解析器接受两条合法路线，拒绝未知路线和空理由。
2. 用户切换路线只生成待确认稿，不改变当前已确认路线。
3. 未确认方案或存在待确认稿时，下游派生路线为 `null`。
4. 确认新路线后派生路线更新，并保留白名单内既有资产版本。
5. 项目总监 Markdown 与制作路线 Markdown 双向链接且包含路线理由。
6. Skill JSON 合同、两段式 UI、确认前双 Wiki 写入均有静态合同测试。

## 9. 验收标准

- 定向测试先红后绿。
- 全量 `pnpm test`、`pnpm exec vue-tsc --noEmit`、`git diff --check` 通过。
- 不新增依赖，不修改 TDD-00 合同，不实现后续模型功能。

## 10. 执行结果

- `jc-film-style`、解析器、Store 门禁和项目总监 UI 已接入两条制作路线；AI 初判后用户可在确认前修改。
- 路线唯一事实源为已确认 `ProjectDirectorPlan.productionRoute`；存在待确认稿时，下游派生路线为 `null`。
- 确认新路线时保留仍在项目总监白名单中的资产 ID、设计和媒体版本，清除声音、分镜、视频和成片等下游。
- 项目总监与制作路线 Wiki 先写入成功，Store 才暴露确认状态；两个页面互相双链。
- 桌面验收发现并修复项目总监页误显示资产按钮栏的问题；修复后右栏显示“生成项目总监方案”。
- 定向 TDD-01 测试 `54/54`、全量测试 `118/118`、`pnpm exec vue-tsc --noEmit` 和 `git diff --check` 全部通过。
