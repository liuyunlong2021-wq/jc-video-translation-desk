# TDD-01：项目总监与制作路线

> 日期：2026-08-03
> 状态：已完成并验证
> 上位设计：`docs/导演分镜时间轴与角色配音编排SDD.md`
> 前置依赖：`docs/tdd/00-共享生产合同与状态机TDD.md`

## 1. 目标

文稿确认后，项目总监只判断内容类型和导演语义（`narration-promo` 或 `drama`），说明原因；声音制作路线由用户在项目总监、资产和分镜之前人工选择。下游分别读取已确认的内容类型和声音制作路线，不另存可能漂移的派生状态。

## 2. 本轮范围

1. `jc-film-style` 的 APP 运行时 JSON 增加 `productionRoute` 和 `routeReason`。
2. 项目总监解析器严格校验两条合法路线和非空理由。
3. 项目总监页显示 `旁白宣传片 | 剧情片` 内容类型信息；声音制作路线在文稿确认区显示 `豆包整段声音轨 | 逐句后配` 两段式控件。
4. Store 从已确认内容类型和用户确认的声音路线派生下游门禁；任一存在待确认稿时关闭下游。
5. 确认方案时保留仍在项目总监资产白名单中的既有资产版本，清除路线相关下游。
6. 确认成功前依次写入 `wiki/项目/项目总监.md`、`wiki/项目/制作路线.md` 和资产页面。

## 3. 明确不做

- 不生成宣传片旁白，不接 Qwen3-TTS 或 IndexTTS2。
- 不接 Faster-Whisper、Gemini 剪辑时间轴或配音字幕工作台。
- 不增加新的顶部阶段、弹窗或独立路线 Store；声音路线复用文稿确认区和共享生产合同。
- 不为未发布旧项目补复杂迁移；无合法路线的旧项目视为项目总监未确认。

## 4. 数据合同

复用 TDD-00 的唯一类型：

```ts
type ProductionRoute = 'narration-promo' | 'drama'
type AudioProductionRoute = 'seed-full-track' | 'post-dub'
```

`ProjectDirectorDraft` 和 `ProjectDirectorPlan` 增加：

```ts
productionRoute: ProductionRoute
routeReason: string
audioProductionRoute: AudioProductionRoute
```

判定规则：

- 统一旁白、解说、产品介绍、知识讲述或广告口播推动全片：`narration-promo`。
- 角色行动、对白、冲突和场景表演推动故事：`drama`。
- 项目中存在角色不等于剧情片；判断依据是叙事驱动力。
- `productionRoute` 是项目总监确认的内容类型；`audioProductionRoute` 是用户确认的声音制作路线。
- 没有确认文稿、内容类型或声音路线时，下游门禁返回 `null`。

## 5. 用户交互

文稿确认区固定显示：

```text
内容类型  [旁白宣传片 | 剧情片]
声音制作路线  [豆包整段声音轨 | 逐句后配]
项目总监理由  ……
```

- AI 草稿生成后，用户可修改内容类型；声音路线由用户直接确认。
- 已确认内容类型切换后转为待确认稿，右栏主按钮变为“确认项目总监方案”；声音路线改变也必须重新确认下游门禁。
- 切换动作本身不失效资产、声音、分镜或媒体；确认时才执行失效。
- 路线控件不放进全局设置，也不增加额外保存按钮。

## 6. Wiki 合同

确认成功后至少存在：

```text
wiki/项目/项目总监.md
wiki/项目/制作路线.md
```

两页互相双链。`制作路线.md` 同时保存内容类型代码、声音路线代码、中文名称、判断理由和用户确认记录。必须先完成 Wiki 写入，再把确认方案暴露给 Store。

## 7. 失效与保留

确认新方案时复用现有项目总监失效入口：清除路线专属声音、分镜、视频、剪辑和成片；保留确认文稿。资产以新项目总监 ID 白名单为准，同类型同名称实体沿用既有 ID、设计和媒体版本，新实体才创建新 ID。

## 8. 测试先行清单

1. 解析器接受两条合法内容类型，拒绝未知类型和空理由。
2. 声音路线只接受 `seed-full-track` 或 `post-dub`，缺失时不开放下游。
3. 用户修改内容类型或声音路线只生成待确认状态，不改变当前已确认状态。
4. 未确认方案或存在待确认稿时，下游派生状态为 `null`。
5. 确认新方案后派生状态更新，并保留白名单内既有资产版本。
6. 项目总监 Markdown 与制作路线 Markdown 双向链接且包含两种路线记录。

## 9. 验收标准

- 定向测试先红后绿。
- 全量 `pnpm test`、`pnpm exec vue-tsc --noEmit`、`git diff --check` 通过。
- 不新增依赖；本次同步已更新 TDD-00 合同，但不实现后续模型功能。

## 10. 执行结果

- `jc-film-style`、解析器、Store 门禁和项目总监 UI 已接入两条内容类型；声音制作路线改为用户人工确认，不再由项目总监替用户决定。
- 内容类型唯一事实源为已确认 `ProjectDirectorPlan.productionRoute`；声音路线唯一事实源为用户确认的 `audioProductionRoute`；任一存在待确认稿时，下游派生状态为 `null`。
- 确认新路线时保留仍在项目总监白名单中的资产 ID、设计和媒体版本，清除声音、分镜、视频和成片等下游。
- 项目总监与制作路线 Wiki 先写入成功，Store 才暴露确认状态；两个页面互相双链。
- 桌面验收发现并修复项目总监页误显示资产按钮栏的问题；修复后右栏显示“生成项目总监方案”。
- 定向 TDD-01 测试 `54/54`、全量测试 `118/118`、`pnpm exec vue-tsc --noEmit` 和 `git diff --check` 全部通过。
- 未接入旁白生成、IndexTTS2、Faster-Whisper、Gemini 时间轴或配音字幕工作台，继续由后续 TDD 串行实现。
