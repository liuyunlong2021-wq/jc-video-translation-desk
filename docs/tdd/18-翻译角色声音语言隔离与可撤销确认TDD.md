# TDD-18：翻译角色声音语言隔离与可撤销确认

> 日期：2026-08-17  
> 状态：已完成  
> 范围：视频翻译模式“角色配音”工作台

## 1. 问题

当前翻译角色只有一个 `voiceProfileId`，没有记录该参考音对应的目标语言；批量生成发现已有参考音后会直接跳过，导致先绑定英语参考音后无法为越南语等目标语言重新生成。角色声音确认也只能确认，不能撤销。

## 2. 目标

- 参考音绑定必须记录当前 `targetLanguage`。
- 当前目标语言与已绑定参考音不一致时，角色显示为待重新准备，不得进入分组克隆。
- 已确认角色可以取消确认；取消确认不删除提示词或参考音，只解除“可用于配音”的门禁。
- 重新生成、上传或更换参考音后自动取消确认；旧声音档案保留在声音库。
- 不改变创作主应用的全局配音主链。

## 3. 最小实现

1. `TranslationRole` 增加可选 `voiceLanguage`。
2. 翻译 Seed 生成、上传和绑定统一使用当前目标语言代码：`zh`、`en`、`vi`、`th`、`id`、`ms`。
3. “确认角色声音”已确认时改为“取消确认”；取消后清除 `voiceConfirmedAt` 并使分组配音失效。
4. 参考音重新生成或选择后写入新的 `voiceLanguage`，并保持未确认状态。
5. 批量生成只跳过“当前目标语言已有参考音”的角色。

## 4. 验收

- 英语已确认角色切换到越南语后显示语言不匹配，不能生成分组配音。
- 越南语重新生成参考音后，角色变为待确认，不再沿用英语确认状态。
- 点击“取消确认”后可以重新生成、上传或选择参考音。
- 重新确认后才恢复分组克隆门禁。
- 原创模式的全局配音、已有声音库档案和其他剧集不受影响。

## 5. 测试

- 角色声音就绪判断包含 `voiceLanguage === targetLanguage`。
- 批量生成会处理语言不匹配的角色。
- 取消确认清除确认状态并保留参考音与提示词。
- 重新绑定参考音会清除确认状态并写入当前语言。
