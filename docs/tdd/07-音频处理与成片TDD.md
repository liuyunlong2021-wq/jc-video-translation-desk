# TDD-07：音频处理与成片

> 日期：2026-08-04
> 状态：已完成并验证
> 上位设计：`docs/导演分镜时间轴与角色配音编排SDD.md`
> 前置依赖：`docs/tdd/06-配音与字幕TDD.md`

## 1. 目标

完成配音字幕工作台最后四个真实动作：分离原人声和背景声、去除原人声、混回背景声/环境声/动作音、烧录配音和字幕。工作台只使用已经确定的七个动作按钮，不再增加“音频模式”或“成片语言”选择器；最终成片必须使用当前人工采用剪辑点、当前按钮链路产生的配音和当前字幕。

## 2. 按钮驱动规则

- 右栏只显示：生成中文配音、翻译所有字幕、生成英语配音、分离原人声和背景声、去除原人声、混回背景声/环境声/动作音、烧录配音和字幕。
- 未执行分离链路时，烧录使用当前已生成配音替换原音；没有对白或旁白时保留原声。
- 用户点击“分离原人声和背景声”即进入保留环境声链路；完成去人声和混回后，烧录自动使用 `mixed.wav`。
- 中文是默认输出；用户主动生成英语配音后，本次烧录使用英语配音与英文字幕。语言是按钮动作产生的内部状态，不提供第二套选择控件。
- 后端可继续使用 `keep-original`、`replace-all`、`replace-preserve-ambience` 作为 FFmpeg 参数，但不得暴露成用户配置。

## 3. 最小执行链路

1. “分离原人声和背景声”先按 `editing-timeline.json` 生成或刷新画面母版，再用 FFmpeg 提取 44.1kHz 双声道 PCM WAV，调用本机 Spleeter ONNX 运行时，生成两个 stem。
2. “去除原人声”只更新采用状态；保留 `vocal.wav`，不删除任何 stem。
3. “混回背景声、环境声和动作音”用 FFmpeg 将当前语言本集配音与 `instrument.wav` 混成唯一最终音轨。
4. “烧录配音和字幕”是唯一最终动作。FFmpeg 使用当前采用剪辑点对应的画面母版、最终采用音轨和当前字幕，输出成片。

## 5. UI 门禁

- 七个动作均为真实按钮，执行中复用现有 `busyAction`、错误提示和停止机制。
- 不显示音频模式、成片语言、保存、确认、试听最终混音或第二个成片按钮。
- 分离完成后才能去除原人声；去除后且当前语言配音已生成才能混音。
- 未开始分离时，当前语言配音和字幕就绪即可烧录；一旦开始分离，必须生成最终混音后才能烧录。
- 只有当前下一步使用主色，已完成动作显示完成态，其余动作保持普通或禁用状态。
- 七个动作统一使用绿色状态体系和至少 `44px` 的按钮高度：当前下一步为实心绿色，已完成为浅绿色，不可执行为灰色。
- “等待时间轴”必须明确区分“待生成 SRT”和“待生成剪辑时间轴”；没有正式 `editing-timeline.json` 时不把分析区间伪装成可采用时间轴。
- 角色列显示“旁白”或项目角色名，禁止显示 `asset-character-*` 等内部 ID。
- 同一原始视频的采用区间按镜头顺序不得重叠；每行缩略视频定位到该行采用起点。
- 不增加保存、确认、试听最终混音或第二个成片按钮。
- 只有文稿页显示左侧项目设置；其余阶段默认隐藏左栏。成片页同时隐藏左右栏，只全宽预览“烧录配音和字幕”生成的最终视频。
- 成片不存在时只提示返回配音字幕工作台完成烧录；成片页不得继承“生成 SRT”等上游动作。

## 6. 测试先行

1. 后期动作合同测试覆盖由按钮推导三种内部音频模式的依赖顺序。
2. 音频处理测试验证 FFmpeg 提取参数、Spleeter 调用、两个 stem 和 `音频处理.json`。
3. 去除原人声测试验证只更新采用状态且 `vocal.wav` 仍存在。
4. 混音测试验证输入为 `instrument.wav` 与当前本集配音，并生成确定的最终 WAV。
5. 成片测试验证最终 FFmpeg 消费最终音轨，不再把未分离的原音与配音混合。
6. Wiki 测试验证成片页和本集制作索引记录最终产物。
7. UI 测试验证七个按钮都有真实事件和正确门禁，且不存在音频模式或成片语言选择器。
8. 持久化测试验证新增路径均相对当前 run。
9. 时间轴测试拒绝同一原始视频内互相重叠的采用区间；UI 测试验证角色人名和按采用点取帧。
10. 全量 `pnpm test`、`pnpm exec vue-tsc --noEmit` 和 `git diff --check` 通过。
