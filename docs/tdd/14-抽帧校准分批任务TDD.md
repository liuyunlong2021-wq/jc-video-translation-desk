# 抽帧校准分批任务 TDD

## 背景

Windows 用户在长视频翻译项目里经常会一次性得到 100 到 200 条字幕。旧实现为了避免单次多模态请求过大，把抽帧校准限制在 30 条以内，导致“一键流程”在真实项目中提前失败。

## 目标

- 前端不再因为字幕条数超过 30 条而拒绝抽帧校准。
- 后端按每批 20 条字幕拆分抽帧校准任务。
- 每个批次写入“当前项目任务”，用户可以看到哪一批成功或失败。
- 再次执行抽帧校准时跳过已成功且结果文件存在的批次，只重跑失败或缺失批次。
- 一个批次失败时保留已成功批次的结果，避免整段工作从头开始。

## 合同

- 批次大小：`20`。
- 任务类型：`frame-calibration`。
- 批次任务 ID：`{episodeId}:frame-calibration:{batchStart}-{batchEnd}`。
- 批次结果落盘到：
  `episodes/{episodeId}/video-translate/frame-calibration/batches/{batchIndex}.json`
- 聚合接口仍返回：
  - `persons`
  - `subtitles`

## 验收

- 45 条字幕会拆成 3 个批次，并产生 3 个任务。
- 成功批次状态为 `success`。
- 批次结果重新执行时可复用。
- 当前项目任务抽屉显示“抽帧校准”。
