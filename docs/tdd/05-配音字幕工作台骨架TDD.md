# TDD-05：配音字幕工作台骨架

> 日期：2026-08-04
> 状态：已完成并验证
> 上位设计：`docs/导演分镜时间轴与角色配音编排SDD.md`
> 前置依赖：`docs/tdd/04-Gemini剪辑时间轴TDD.md`

## 1. 目标

剪辑时间轴完成后，把现有七阶段中的“配音”阶段正式改为“配音字幕”，并进入一个可见、可核对的后期工作台。工作台先提供稳定的 UI 骨架和状态门禁，后续 TDD 再逐项接入真实配音、翻译、分离、混音和烧录能力。

## 2. 本轮范围

1. 顶部仍保持七个阶段；第六阶段标签为“配音字幕”，不新增第八阶段。
2. `workflowStep === 'voice'` 且剪辑时间轴就绪时，点击顶部阶段进入独立的配音字幕工作台。
3. 中栏工作台包含：原始视频预览、当前素材时间轴范围、逐素材表格，以及角色、配音试听、中文字幕、英文字幕六列信息。
4. 右栏显示后续动作按钮：重选剪辑点、生成中文配音、翻译所有字幕、生成英语配音、分离原人声和背景声、去除原人声、混回背景声/环境声/动作音、烧录配音和字幕。
5. 本轮只实现按钮、占位状态和导航；真实动作由后续 TDD 实现。不得伪造已生成音频、字幕、混音或成片。

## 3. 明确不做

- 不新增 IPC、IndexTTS2 逐句生成、翻译 API、人声分离、FFmpeg 混音或字幕烧录。
- 不增加“保存字幕”“确认最终时间轴”“试听最终混音”“设为入点/出点/保存剪辑点”等按钮。
- 不把旧的统一配音生成页面继续当作本阶段入口。

## 4. 状态与门禁

- 全部视频素材完成后即可提前进入工作台查看现有素材和后续结构，避免阶段完全不可见。
- 未完成全部素材 SRT 和 `editing-timeline.json` 时，工作台显示“等待时间轴”；所有后续动作保持禁用，不能绕过正式门禁。
- 工作台表格使用当前 `segments` 和 `editingAnalysis` 展示已有证据；未存在的角色、字幕、试听文件显示“待生成”。

## 5. 验收标准

1. 顶部阶段仍为七个，且包含“配音字幕”。
2. 时间轴就绪后点击该阶段，`workspaceView` 为工作台视图而非旧成片视图。
3. 中栏出现视频预览与六列表格。
4. 右栏出现八个指定动作按钮。
5. 代码中没有本轮不需要的保存/确认/最终混音试听控制。
6. 定向合同测试、全量 `pnpm test`、`pnpm exec vue-tsc --noEmit`、`git diff --check` 全部通过。
7. 镜头超过可视高度时表格独立纵向滚动且表头保持可见；预览区不随表格滚走。
8. 横屏、竖屏统一使用左侧预览/右侧表格；进入工作台时自动收起左栏，右栏可手动收起，两栏都收起即为最大空间模式。
9. 点击任意素材行后，主预览切换到该素材，从当前剪辑起点播放并在终点暂停。

## 6. 执行结果

- 新增 `DubbingSubtitleWorkspace.vue`，提供原始视频预览、逐素材时间轴滑块和六列表格。
- 七阶段第六阶段改为“配音字幕”，`voice` 工作流进入独立 `dubbing` 视图；未增加第八阶段。
- 右栏展示八个后期动作按钮，当前全部明确为待接入禁用态；旧统一配音/画面母版入口不再作为本阶段入口。
- 修复长表格无法向下滚动；横竖屏统一采用左侧预览/右侧表格，压缩表格固定列并把中文字幕留作主要弹性列，表头吸顶。
- 配音字幕阶段自动收起左侧项目设置，顶部双箭头可分别展开/收起左右栏；双栏收起时中栏自然最大化。
- 点击素材行会切换主预览，从该行剪辑起点播放并在终点自动暂停；调整滑块时主预览同步定位。
- 时间轴未就绪时禁用逐行滑块；右栏移除重复的底部“返回配音字幕工作台”按钮。
- 定向合同测试、全量测试、类型检查和 diff 检查通过；本轮未调用真实配音、翻译、分离、混音或烧录引擎。
