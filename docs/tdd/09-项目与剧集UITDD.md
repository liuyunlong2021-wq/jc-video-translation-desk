# TDD-09：项目与剧集 UI

> 状态：已完成
> 依赖：`docs/tdd/08-项目与剧集数据边界TDD.md`

## 目标

让已存在的项目/剧集数据边界在桌面 UI 中可用：用户能够重命名项目、查看当前剧集、新建剧集并切换剧集。

## 用户流程

1. 顶部项目选择器选择项目。
2. 顶部剧集选择器显示当前项目的所有剧集，切换后只加载目标剧集状态。
3. 点击“新建集”创建下一个集数的空制作状态；项目共享资产、风格、模型和声音设置继续复用。
4. 点击铅笔进入项目名编辑，确认后写入项目清单；取消或空值不产生修改。

## 数据与门禁

- 项目清单继续保存 `episodes[]` 和 `lastOpenedEpisodeId`。
- 新集使用唯一的 `episodeId`，只写入该集 `episodes/<episodeId>/state.json`；不得覆盖其他集或共享状态。
- 切集必须显式把 `projectId` 和 `episodeId` 传给加载 IPC，不从 UI 隐式推断。
- 重命名只修改项目清单，并触发已有 Wiki 重建；失败时保留原名称并提示错误。
- 不做旧版本迁移、删除集、集级权限或额外项目管理页面。

## UI 验收

- 项目栏同时显示项目选择器、剧集选择器、“新建集”和重命名入口。
- 重命名入口可见、可编辑、可保存和取消，不能依赖浏览器 `prompt`。
- 没有项目或切换/保存进行中时，相关控件禁用。
- 新建集后自动切换到新集，工作区回到文稿起点；旧集仍可切回且状态不变。
