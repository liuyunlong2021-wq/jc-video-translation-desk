# 16 - 东南亚字幕翻译语种 TDD

## 背景

产品服务范围从北美扩展到东南亚。字幕工作台需要先开放明确合作与高频目标语言，再进入配音工作台简化。

## 范围

- 目标语言新增越南语 `vi`、泰语 `th`、印尼语 `id`、马来语 `ms`。
- 英语仍按美国观众本地化。
- 东南亚语种只改字幕翻译入口和翻译 Prompt，不改截图、OCR、人物识别或配音工作台。

## 合同

- 左侧“目标语言”下拉必须显示四个新增语种。
- 字幕表格标题必须使用中文语言名，不显示裸代码。
- 翻译 Prompt 必须把 `targetLanguage` 连接到目标地区说明：
  - `vi`：面向越南观众，使用自然当代越南语对白。
  - `th`：面向泰国观众，使用自然当代泰语对白。
  - `id`：面向印尼观众，使用自然 Bahasa Indonesia。
  - `ms`：面向马来西亚观众，使用自然 Bahasa Melayu，避免写成印尼语。
- 目标语言仍使用安全语言代码，不新增自由输入。

## 验证

- 定向运行字幕翻译运行时测试。
- 运行 TypeScript 类型检查。
- 运行 `git diff --check`。
