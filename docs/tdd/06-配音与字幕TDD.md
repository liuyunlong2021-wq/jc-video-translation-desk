# TDD-06：配音与字幕

> 日期：2026-08-04
> 状态：已完成并验证
> 上位设计：`docs/导演分镜时间轴与角色配音编排SDD.md`
> 前置依赖：`docs/tdd/05-配音字幕工作台骨架TDD.md`

## 1. 目标

在现有配音字幕工作台内完成可用的逐句中文字幕、中文配音、整批英文翻译和英文配音链路。用户调整后的剪辑点、字幕和逐句音频都必须写入当前项目，重新打开项目后仍可继续工作。

## 2. 本轮范围

1. 时间轴滑块调整后，更新唯一的 `wiki/剪辑/episode-001/editing-timeline.json`；保留 Gemini 原始区间，人工区间标记为 `adoptedBy: user` 并递增 `revision`。
2. 中文字幕改为可编辑输入框，修改后自动持久化，不新增保存按钮；同步更新分镜台词和 `wiki/字幕/episode-001-zh.srt`。
3. 启用“生成中文配音”，复用现有 IndexTTS2 批处理，按台词生成独立 WAV 和本集 WAV。
4. 六列表格按行试听中文配音；不存在音频时显示待生成。
5. 启用“翻译所有字幕”，使用用户当前选择的 `textModel` 一次性翻译全部非空中文字幕，并校验 ID、数量和非空结果。
6. 英文字幕只读显示，写入项目状态和 `wiki/字幕/episode-001-en.srt`。
7. 启用“生成英语配音”，仍复用 IndexTTS2 批处理，按英文台词生成独立 WAV 和本集 WAV。
8. 六列表格按行试听英文配音。

## 3. 明确不做

- 不接入 Spleeter、人声分离、去除原人声、环境声混音和字幕烧录。
- 不增加保存字幕、确认时间轴、最终混音试听等按钮。
- 不新增配音任务数据库或第二套时间轴；状态直接沿用现有 `segments`、`editingTimeline` 和项目 Wiki。
- 不自动生成英语字幕或英语配音，只有用户点击对应按钮才执行。

## 4. 数据合同

每个分镜允许持久化：

```ts
englishDialogueText?: string
chineseVoicePath?: string
chineseVoiceDuration?: number
englishVoicePath?: string
englishVoiceDuration?: number
```

IndexTTS2 批处理结果必须返回本集音频及与输入任务一一对应的逐句音频路径和时长。翻译接口必须返回与输入 `shotId` 完全一致的英文文本列表，禁止缺行、增行或串行。

## 5. Wiki 产物

- `wiki/剪辑/episode-001/editing-timeline.json`
- `wiki/声音/episode-001/对白资产.json`
- `wiki/声音/episode-001/episode-voice-zh.wav`
- `wiki/声音/episode-001/episode-voice-en.wav`
- `wiki/字幕/episode-001-zh.srt`
- `wiki/字幕/episode-001-en.srt`

`对白资产.json` 记录语言、镜头、角色、原文、情绪、目标时间窗、逐句 WAV、实际时长和状态，作为后续混音阶段的唯一对白资产索引。

## 6. UI 与门禁

- 时间轴未完成时，三个动作按钮全部禁用。
- “生成中文配音”要求存在非空中文字幕、角色 ID 和已绑定音色包。
- “翻译所有字幕”要求配置 API 且存在非空中文字幕。
- “生成英语配音”要求全部非空中文字幕均已有英文翻译。
- 动作执行中复用现有 `busyAction`、错误区和停止机制；不得伪造成功。
- 中文字幕使用原生多行输入，失焦或短延迟后自动持久化；英文字幕保持只读。
- 配音试听使用原生 `audio controls`，中文和英文音频按行显示在同一“配音试听”列。

## 7. 测试先行

1. 时间轴测试：人工剪辑点保留 Gemini 区间，重算输出时间轴并递增版本。
2. 配音结果测试：IndexTTS2 返回逐句音频与本集音频，输出条数和任务严格一致。
3. 翻译合同测试：当前模型被传入；错 ID、缺行、空英文必须失败。
4. 持久化测试：逐句中英文音频路径使用项目相对路径，中文字幕、英文字幕和人工剪辑点可恢复。
5. 工作台测试：三个按钮真实可点击，中文字幕可编辑、英文只读、逐句音频可试听；后续五个按钮仍禁用。
6. 全量 `pnpm test`、`pnpm exec vue-tsc --noEmit` 和 `git diff --check` 通过。

## 8. 执行结果

- 时间轴滑块释放后写回唯一 `editing-timeline.json`；Gemini 区间保持不变，人工区间和修订号可随项目状态恢复。
- 中文字幕可在表格内直接编辑，400ms 后自动更新时间轴和 `episode-001-zh.srt`；英文字幕只读并由“翻译所有字幕”生成。
- 三个真实动作按钮已启用：生成中文配音、翻译所有字幕、生成英语配音；其余后期动作继续保持禁用。
- IndexTTS2 按语言生成逐句 WAV、本集 WAV 和唯一 `对白资产.json`，工作台可逐句试听中英文配音。
- 翻译严格使用当前 `textModel`，错 ID、缺行或空文本会自动重试一次，仍错误则停止。
- 人声分离、去除原人声、环境声混音和字幕烧录未提前实现。
- 定向测试、134 项全量测试、`pnpm exec vue-tsc --noEmit` 均通过。
