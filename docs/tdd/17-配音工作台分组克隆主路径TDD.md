# 17 - 配音工作台分组克隆主路径 TDD

## 背景

字幕工作台已完成自动角色识别和自动关联配音分组。进入配音工作台后，产品主路径应继续保持简单：确认角色参考音后，用一个批量按钮完成全局声音基底、分组提示词和分组克隆音频。

## 范围

- 视频翻译产品的配音工作台隐藏“全局配音”入口。
- 不新增“生成全局提示词”按钮；全局声音基底由“批量生成全部分组配音”内部自动生成。
- 创作主应用里的 Seed 全局配音路线继续保留，不硬删后端和历史产物读取。

## 合同

- 翻译模式第二页只提供 `角色配音` 和 `分组克隆` 两个工作区入口。
- 用户确认全部角色声音后，可直接点击唯一生成按钮 `批量生成全部分组配音`。
- 该按钮固定按 `整集全局声音基底 -> 每个分组提示词 -> 分组参考音映射 -> 每个分组音频` 执行；参考音仍须由角色配音页人工确认，按钮不得跳过该门禁。
- 全局声音基底由 `jc-luyinpeng` 通读整集确认译文、角色声音身份和表演方向生成；每个分组再把该基底、完整剧本、当前组字幕和该组参考音传回 `jc-luyinpeng`，生成承接全剧情绪弧线的最终分组提示词。
- 全局声音基底、分组提示词和分组音频均按最多 3 个并发限流执行；已成功的分组提示词和音频保留，失败后再次点击同一按钮只补缺失或失败项。
- 右侧操作区显示当前阶段进度：全局声音基底、分组提示词、分组音频分别显示完成数、失败数或当前分组；右上角任务抽屉继续显示每个分组音频任务状态。
- 分组克隆运行时不再使用仅由当前组字幕确定性拼接的弱提示词；分组提示词校验采用声音导演稿的角色定义与逐句台词合同，不强制“时长为 X 秒”的机械首句。
- 缺少角色参考音、角色声音身份或人工确认时，分组克隆按钮必须置灰并提示缺项。
- 旧的全局配音后端、版本列表和成片兼容逻辑不在本轮删除。

## 验证

- 定向运行视频翻译运行时测试。
- 运行 TypeScript 类型检查。
- 运行 `git diff --check`。
