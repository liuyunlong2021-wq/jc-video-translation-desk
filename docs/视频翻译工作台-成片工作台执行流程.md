# 视频翻译工作台“成片工作台”执行流程

> 状态：FunASR 整块英文词级对齐已接入；相邻 cue 尾词重复的边界余量仍待后续小幅收紧（2026-08-10）。
>
> 范围：只定义视频翻译第三阶段“成片工作台”。字幕工作台和配音工作台另行定义。

## 1. 目标

成片工作台只把人工试听通过的目标语言配音剪成逐句人声，按最终时间戳剧本贴回原片，再恢复原片音乐、环境声和音效，烧录字幕并生成翻译成片。

```text
配音工作台当前采用版本
-> 分离并移除原片人声
-> FunASR 整块识别配音真实发音时间
-> 按顺序约束和英文词流单调匹配绑定 cueId
-> FFmpeg 按真实发音时间剪出每句配音
-> 按原字幕固定时间戳填充配音
-> 与原片背景声混合
-> 烧录字幕并生成翻译成片
```

不再使用：

- 分离生成配音的人声。
- FFmpeg 识别前固定 10 秒切片。
- Gemini 逐片听音频猜测时间。
- Whisper、字符数、平均时长或第二套 ASR 补齐。

## 2. 唯一输入

成片工作台只消费：

```text
最终时间戳剧本
finalScriptId
scriptHash
activeVoiceVersionId
当前配音版本 manifest
按顺序排列的 voiceBlockId
每块有序 cueIds
每块原始配音音频路径、SHA-256 和时长
原片或当前无字幕成片母版
```

入口必须验证：

- `activeVoiceVersionId` 指向完整成功的配音版本。
- 配音版本绑定当前 `finalScriptId` 和 `scriptHash`。
- 所有配音块的有序 `cueIds` 合并后与最终剧本完全一致。
- 每块音频存在且实际 SHA-256 与 manifest 一致。
- 原片或母版存在有效画面和音频流。

成片工作台不再读取角色参考音、声音身份或提示词。这些信息只用于上游生成配音，已由配音版本 manifest 追溯。

## 3. UI 只保留三个主按钮

顶部保留工作台切换：

```text
字幕工作台 | 配音工作台 | 成片工作台
```

成片工作台只保留三个主操作，严格按顺序开放：

```text
1. 分离并移除原片人声
2. 填充目标语言配音
3. 生成翻译成片
```

不单独显示“FunASR识别”、“对齐 cueId”、“剪句”、“合成目标语言音轨”或“烧录字幕”等技术按钮。这些都是三个主按钮内的可恢复后端阶段，UI 只显示当前进度和明确失败原因。

## 4. 按钮一：分离并移除原片人声

按钮文案固定为：

```text
分离并移除原片人声
```

输入必须是用户上传的原片或更高质量母版，不使用任何分析压缩片。执行：

```text
原片音轨
-> original-vocal.wav
-> original-background.wav
```

- `original-vocal.wav` 只留档，不混回翻译成片。
- `original-background.wav` 保留原片音乐、环境声和音效，是翻译成片的背景轨。
- 不覆盖或删除原片音频。
- 分离结果按原片指纹复用；原片未变时不重复计算。

## 5. 按钮二：填充目标语言配音

按钮文案固定为：

```text
填充目标语言配音
```

该按钮内部按配音版本的块顺序执行五步。

### 5.1 准备识别音频

配音工作台输出已经是音频，不再“从视频提取音频”。FunASR 识别前只用 FFmpeg 把每个配音块转成 16 kHz、单声道 PCM WAV 识别副本。原始 48 kHz 配音块永不覆盖。

这一步不切片、不剪句，不改变正式配音音质。

### 5.2 FunASR 整块识别

复用字幕工作台已验证的本地 FunASR 运行时：

```text
SenseVoiceSmall
+ FSMN-VAD
+ CT-Punc
```

FunASR 一次读取完整配音块。FSMN-VAD 在模型内找发声区间，不由 FFmpeg 预先切成 10 秒片。当前使用英文词级时间戳作为对齐证据；FunASR 的识别文字不得覆盖最终剧本的 `translatedText`。

### 5.3 绑定 cueId

绑定规则不是逐片猜测，而是完整配音块的一次单调匹配：

```text
顺序是硬约束
+ 已确认英文台词和 FunASR 英文词流按字符顺序匹配
+ FunASR 词级时间是首尾边界
```

程序只把最终英文台词和完整配音块的 FunASR 英文词流做一次字符级单调匹配；大小写、标点、连字符和缩写不影响匹配。每个 cue 的首个匹配词作为真实开始，最后一个匹配词作为真实结束。

必须处理：

- FunASR 把两句合成一句：使用完整词流和已知台词的单调匹配拆回两个 `cueId`。
- FunASR 把一句拆成多段：所有匹配到该 cue 的词合并为一个真实范围。
- 重复短句：用 `cueId` 顺序和前后台词限定，不按全文第一次命中。
- 极短语气词没有识别词：保留前一句尾词与后一句首词之间的完整声音，不按字符数平均时间。
- 有识别词但内容无法稳定匹配：保留 FunASR 证据并阻止进入成片，要求人工确认或重新生成配音。

### 5.4 FFmpeg 按真实发音剪句

每个成功对齐的 `cueId` 保存两套时间：

```text
sourceStartMs / sourceEndMs：在当前配音块中的真实发音位置
targetStartMs / targetEndMs：最终时间戳剧本在原片中的固定位置
```

FFmpeg 只根据 `sourceStartMs/sourceEndMs` 从原始高质量配音块剪出 `<cueId>.wav`，不从 16 kHz 识别副本剪正式句子。

### 5.5 填充并混合

每句 `<cueId>.wav` 从 `targetStartMs` 开始放入与原片等长的目标人声轨，再与按钮一产生的 `original-background.wav` 混合：

```text
original-background.wav
+ 按 targetStartMs 放置的所有 <cueId>.wav
-> mixed.wav
```

- 原字幕时间戳始终不变。
- 不自动截断、压缩、拉伸或重新生成已试听通过的配音。
- 某句超出 `targetEndMs` 或与下一句重叠时写 warning，保留完整表演。
- 原剧存在抢话时允许目标人声重叠。

## 6. 按钮三：生成翻译成片

按钮文案固定为：

```text
生成翻译成片
```

执行：

- 画面优先使用当前无字幕高质量母版；不存在时使用原片。
- 音轨只使用按钮二生成的 `mixed.wav`。
- 字幕只使用最终时间戳剧本中的 `translatedText` 和原始 `targetStartMs/targetEndMs`。
- 每次点击生成新的 `finalVideoVersionId`，不覆盖原片或历史成片。

## 7. 按钮门禁

| 按钮                 | 可用条件                                                          |
| -------------------- | ----------------------------------------------------------------- |
| `分离并移除原片人声` | 原片或母版存在且包含有效音频流                                    |
| `填充目标语言配音`   | 原片背景轨已完成；当前配音版本与最终剧本通过入口校验；FunASR 可用 |
| `生成翻译成片`       | `mixed.wav`、当前最终剧本、字幕样式和画面源可用                   |

按钮二执行中的任一 FunASR 或对齐阶段失败时，按钮三保持禁用。UI 必须显示失败的 `voiceBlockId` 和待人工确认的 `cueId`，不用“处理失败”等笼统文案。

## 8. 产物

```text
episodes/<episodeId>/video-translate/<targetLanguage>/原片声音/original-vocal.wav
episodes/<episodeId>/video-translate/<targetLanguage>/原片声音/original-background.wav
episodes/<episodeId>/video-translate/<targetLanguage>/配音对白时间戳/<voiceVersionId>/<voiceBlockId>/recognition.wav
episodes/<episodeId>/video-translate/<targetLanguage>/配音对白时间戳/<voiceVersionId>/cues/<cueId>.wav
episodes/<episodeId>/video-translate/<targetLanguage>/target-voice.wav
episodes/<episodeId>/video-translate/<targetLanguage>/mixed.wav
wiki/翻译/<episodeId>/成片/配音对白时间戳.json
episodes/<episodeId>/video-translate/final/<targetLanguage>/<finalVideoVersionId>.mp4
wiki/翻译/<episodeId>/成片/成片记录.json
```

`配音对白时间戳.json` 必须保存：

```text
finalScriptId
scriptHash
voiceVersionId
voiceBlockId
cueId
FunASR 识别证据
sourceStartMs / sourceEndMs
targetStartMs / targetEndMs
对齐置信度和人工确认状态
dubDialogueTimestampHash
```

## 9. 失效和重试

| 修改内容                    | 保留                                     | 失效                                 |
| --------------------------- | ---------------------------------------- | ------------------------------------ |
| 最终时间戳剧本变化          | 原始配音历史版本                         | 配音对白时间戳、逐句音频、混音和成片 |
| 切换 `activeVoiceVersionId` | 所有历史配音版本、原片分离结果           | 配音对白时间戳、逐句音频、混音和成片 |
| 当前版本单个配音块变化      | 其他块 FunASR 和对齐检查点、原片分离结果 | 当前块时间戳和逐句音频、混音和成片   |
| 更换原片或母版音频          | 配音对白时间戳和逐句目标人声             | 原片分离结果、混音和成片             |
| 只修改字幕样式              | 配音对白时间戳、逐句音频和混音           | 成片                                 |
| FunASR 或单块对齐失败       | 其他成功配音块、原片分离结果             | 当前失败块及依赖它的混音和成片       |

重试只重跑失败的配音块，不重复分离未变的原片，不删除最终剧本、历史配音版本或已成功检查点。

## 10. ID

```text
finalScriptId：最终时间戳剧本版本
scriptHash：最终时间戳剧本完整校验
cueId：对白稳定 ID
translationRoleId：角色稳定 ID
voiceVersionId：当前消费的完整配音结果 ID
activeVoiceVersionId：人工选中的 voiceVersionId
voiceBlockId：voiceVersionId 内的配音块 ID
dubDialogueTimestampHash：配音真实发音时间文件校验
finalVideoVersionId：一次翻译成片导出 ID
```

不创建新的切片 ID、Gemini 分析 ID、`referenceAudioId`、配音项目总监 ID 或分段声音设计 ID。逐句音频通过 `voiceVersionId + voiceBlockId + cueId` 追溯。

## 11. 验收标准

1. 成片工作台只消费 `activeVoiceVersionId` 指向的人工试听版本。
2. UI 只显示“分离并移除原片人声”“填充目标语言配音”“生成翻译成片”三个主按钮。
3. 配音块只转换一份 16 kHz 单声道识别副本，不做 10 秒切片或配音人声分离。
4. FunASR 整块识别真实发音时间，不使用 Gemini 或 Whisper 猜测。
5. cue 绑定同时使用顺序硬约束和内容相似度；合句、拆句和重复短句不错绑。
6. 无法稳定对齐时要求人工确认，不按字符数平均时间。
7. FFmpeg 从原始高质量配音块剪句，根据 `targetStartMs` 贴回原片。
8. 原片时间戳、正式译文、角色和台词顺序全程不变。
9. 原片人声不混回成片；原片音乐、环境声和音效与目标语言配音混合。
10. 最终成片能够从 `finalVideoVersionId` 追溯到剧本、配音版本、FunASR 证据和配音对白时间戳。
