# 创作参数与品牌视觉升级 SDD

> 日期：2026-07-30
> 状态：Phase 1、Phase 2 已实施
> 目标版本：2.2
> 依赖：`docs/短视频工厂AI原生创作改造SDD.md`、`docs/镜头节奏控制SDD.md`

## 1. 目标

在不改变现有“文稿 -> 统一配音 -> 单幅分镜图 -> 单镜头视频 -> 本地合成”主链路的前提下，完成三项升级：

1. 把宽泛视觉风格替换为可直接执行的分组预设；
2. 把固定 `10 / 15 / 30` 秒改为快捷时长加自定义时长；
3. 将产品展示品牌改为“赚钱短片”，统一 Logo 与主操作颜色，同时保留历史素材。

本 SDD 不增加内容用途分类，不增加真人口型同步、数字人、多角色一致性或背景音乐。

## 2. 不变的流程

目标时长必须在生成文稿前确定：

```text
选择目标时长和视觉风格
  -> 模型按目标时长控制文稿篇幅
  -> 用户编辑并确认文稿
  -> 生成配音并读取真实音频时长
  -> 按真实配音时长和镜头节奏拆镜
  -> 生成图片、视频并合成
```

- `targetDuration` 只约束文稿长度和前期费用预估；
- `voiceDuration` 是分镜、时间线和成片长度的唯一事实来源；
- 不为凑目标秒数截断或拉伸配音；
- 当前能力覆盖广告、产品展示、旁白讲解、知识科普、历史解说和企业介绍等旁白型内容；
- “真人出镜并准确对口型”的口播不在当前能力承诺内。

## 3. 视觉风格模型

### 3.1 两层选择

风格采用“媒介分组 + 具体预设”两层结构。媒介只负责组织菜单，不直接作为生成参数：

```ts
type VisualMedium = 'live-action' | 'animation-2d' | 'animation-3d' | 'stop-motion'

interface VisualStylePreset {
  id: string
  medium: VisualMedium
  label: string
  description: string
  prompt: string
}
```

用户最终选择的必须是具体 `VisualStylePreset`。禁止再把“真人电影”“日系动画”“国风动画”或“3D”这种大类直接交给模型。

### 3.2 首批预设

| 分组 | `id` | 界面名称 | 固定视觉合同 |
|---|---|---|---|
| 真人 | `cinematic-contrast` | 冷暖对比电影 | 暖色主体光、冷色环境光，中高反差，真实肤色和材质，克制电影调色，稳定摄影机；禁止赛博霓虹滥用、塑料皮肤、插画和 CGI 感 |
| 真人 | `commercial-bright` | 明亮通透商摄 | 高调棚拍或柔和日光，大面积干净高光，通透材质，清晰轮廓，精准产品色，商业广告镜头；禁止脏灰、硬黑阴影、过曝和主体变形 |
| 真人 | `natural-documentary` | 自然光纪实 | 可用自然光、低饱和真实色、适度手持或旁观机位、环境细节和生活质感；禁止影棚摆拍、夸张特效、过度磨皮和强行戏剧光 |
| 二维动画 | `ink-wash` | 水墨写意动画 | 墨分五色、宣纸纹理、无勾线或克制笔线、晕染与大面积留白；禁止西式水彩、赛璐璐阴影、三维渲染和现代霓虹 |
| 二维动画 | `cel-cinematic` | 日系电影赛璐璐 | 清晰线稿、分层赛璐璐上色、自然天空与环境光、电影式构图、克制高光；禁止指定作品角色、夸张热血特效、三维塑料感和风格漂移 |
| 二维动画 | `gongbi-color` | 工笔重彩动画 | 铁线描、矿物颜料、朱砂石青石绿、大色块平涂、东方装饰构图；禁止日系赛璐璐、写实摄影、数字渐变和西式卡通造型 |
| 三维动画 | `eastern-xianxia-cg` | 东方仙侠写实 CG | 写实人物与织物、青绿山水、法宝金光、体积雾和克制灵气粒子、东方电影运镜；禁止欧美盔甲套用、游戏 UI、低模和廉价特效 |
| 三维动画 | `realistic-fantasy-cg` | 写实奇幻电影 CG | 照片级 PBR 材质、冷暖电影光、高反差、体积粒子、可信人物比例和史诗空间；禁止卡通比例、低模、过度光晕和游戏截图感 |
| 定格动画 | `handmade-clay` | 手工粘土定格 | 可见粘土与织物纹理、手作微瑕、微缩布景、柔和棚拍光、逐格动画质感；禁止光滑 CGI、真人摄影和材质漂移 |

首批只实施以上 9 项。赛博朋克、末日、宏大红色撞色、黑白电影、剪纸、敦煌壁画、像素和其他细分风格留到完成实际生图与图生视频验收后再增加。

### 3.3 Skill 与 Reference 的关系

- `skills/jc-gpt-image/references/` 是设计与测试依据，不在运行时整库注入模型；
- 每个首批预设从 Reference 中提炼为一个短而完整的固定 `prompt`；
- `jc-script-storyboard` 与 `jc-gpt-image` 必须接收同一份已解析预设；
- `prompt` 必须覆盖媒介、材质、光线、色彩、镜头语言和禁止项；
- 预设写入全片 `visualAnchor`，每镜只允许在内容和构图上变化；
- 不在产品内运行 `jc-film-style` 的浏览器搜图和多轮导演选择流程。

### 3.4 界面

- 风格控件使用分组下拉菜单；分组标题不可选，具体预设可选；
- 当前选项显示名称和一句短描述，不在主界面展示完整提示词；
- 第一版不提供用户自定义风格提示词，避免绕过一致性合同；
- 更换风格保留用户诉求、文稿、声音方案和配音，清空分镜计划、分镜图、视频和成片；
- 旧任务中的 `live-action / illustration / 3d / clay` 按第 7 节迁移。

## 4. 动态目标时长

### 4.1 数据合同

```ts
type TargetDuration = number // 整数，5..180，单位秒
```

- 快捷选项：`15 / 30 / 60` 秒；
- 自定义范围：`5..180` 秒，只接受整数；
- 默认值：`15` 秒；
- 旧值 `10 / 15 / 30` 全部继续合法；
- Electron 主进程和渲染进程必须执行同一范围校验，不能只依赖输入控件。

### 4.2 交互与费用提示

- 时长控件使用 `15 / 30 / 60 / 自定义`，选择自定义后显示数字输入框；
- 文稿生成前显示预计字数：`round(targetDuration / 60 * 200)`；
- 在已有镜头节奏下显示预计镜头数；自动节奏只显示范围，不伪造确定值；
- 配音生成后用真实时长更新准确镜头数；
- 预计图片或视频任务超过 20 个时，在用户点击对应付费阶段前显示一次任务数量确认；
- 用户取消确认不得提交任何媒体任务。

## 5. 品牌与 Logo

### 5.1 产品名称

- 中文展示名：`赚钱短片`；
- 英文展示名：`Money Clips`；
- 页面标题、菜单、关于窗口、安装包 `productName` 和可见文案统一更新；
- `package.json.name`、Electron `appId` 和 GitHub 仓库地址本版保持不变。

### 5.2 数据兼容

Electron 的 `userData` 中保存 API Key、任务状态和全部生成素材。品牌改名不得让应用切换到新的数据目录。

实施时必须先记录旧 `userData` 绝对路径，并满足以下任一方式：

1. 在应用初始化最早阶段把 `userData` 显式固定到旧目录；或
2. 首次启动新品牌时原子迁移旧目录，并保留失败回退。

第一版优先选择“继续使用旧目录”，不做无收益的数据搬迁。升级后必须能够恢复改名前的最近任务和媒体库。

### 5.3 Logo 资产

以用户提供的头像图为识别参考，重新绘制，不做自动描摹：

- 只保留脸型、眼镜和发型三个识别特征；
- 移除原图文字、篮球和复杂速度线；
- 使用黑色与品牌绿双色，透明背景；
- 小尺寸下保持清楚，不依赖细碎线条；
- 主源文件为 SVG，另导出透明 PNG 和 macOS ICNS；
- 应用图标不得包含“赚钱短片”文字，产品名由界面和系统标签承担。

最终 Logo 需先由用户确认黑白/双色预览，再替换 `public/icon.png` 和打包图标。

## 6. UI 颜色

品牌主色暂定为可访问性较好的韭菜绿：

```text
Primary: #15803D
Primary hover/active: #166534
Selected background: #DCFCE7
Selected border/text: #15803D
```

- “生成文稿、确认文稿、生成声音方案、生成配音、生成分镜图、生成视频、合成视频、保存”等当前阶段主操作使用品牌绿；
- 同一区域同一时刻只应有一个视觉上的主操作；
- 次要操作使用白色、灰色、描边或文字按钮；
- 删除、停止和破坏性操作继续使用红色；
- 禁用状态使用中性灰，不使用浅绿色冒充可点击；
- 链接、信息提示和媒体状态不强制全部变绿，避免失去语义层级；
- 正文与品牌绿的对比度必须满足 WCAG AA。

## 7. 迁移与失效规则

### 7.1 旧风格映射

| 旧值 | 新值 |
|---|---|
| `live-action` | `cinematic-contrast` |
| `illustration` | `cel-cinematic` |
| `3d` | `realistic-fantasy-cg` |
| `clay` | `handmade-clay` |

- 恢复旧任务时在内存和下一次持久化中迁移；
- 已生成媒体不得因为枚举升级而从媒体库消失；
- 旧任务已有分镜时保留素材和旧 `visualAnchor`，不偷偷按新预设重写；
- 用户主动重新选择风格时才清空视觉下游。

### 7.2 时长变更

- 文稿确认前修改目标时长，只影响下一次文稿生成和估算；
- 已有文稿时修改目标时长，将文稿标记为需重新生成或重新确认；
- 已生成配音后不得仅修改目标时长来重排现有成片；要生效必须重新确认文稿并重新生成声音链路；
- 历史 `10` 秒任务无需迁移。

## 8. 实施范围

### Phase 1：创作参数

1. 增加 9 个具体风格预设和分组菜单；
2. 更新 `jc-media-script`、`jc-script-storyboard`、`jc-gpt-image` 的风格输入说明；
3. 实施 `15 / 30 / 60 + 5..180` 秒；
4. 增加旧 Store 数据迁移、费用预估和必要测试。

### Phase 2：品牌视觉

1. 将可见产品名更新为“赚钱短片”；
2. 统一 Vuetify 主色和各阶段主操作；
3. 绘制并确认简化头像 SVG；
4. 导出 PNG、ICNS 并替换桌面打包图标；
5. 验证旧数据目录、安装包名称和应用启动。

两个 Phase 可独立提交。Logo 未经用户确认不得阻塞 Phase 1。

## 9. 验收标准

1. 风格菜单按真人、二维动画、三维动画、定格动画分组，并且只能选择 9 个具体预设。
2. 每个预设均包含媒介、材质、光线、色彩、镜头语言和禁止项，并完整进入分镜与图片 Skill。
3. 修改风格只让视觉链路失效，文稿和配音保留。
4. 用户可选择 15、30、60 秒或输入 5–180 秒整数；5、10、60、180 合法，4、181、小数和非数字被拒绝。
5. 文稿按目标时长生成；分镜与成片继续按真实配音时长执行。
6. 超过 20 个付费图片或视频任务时，提交前显示准确数量并等待确认。
7. 所有可见产品名改为“赚钱短片”，主操作统一使用品牌绿且保留危险色和禁用态。
8. Logo 具有 SVG、透明 PNG 和 ICNS 产物，小尺寸可辨认且不含文字。
9. 升级后旧 API Key、最近任务和 `media-runs` 素材仍可读取；旧风格任务不会丢失已有媒体。
10. 自动测试、类型检查、Wiki 校验和本地未签名应用打包通过；至少人工恢复一个改名前任务。
