# 导演分镜时间轴与角色配音编排 SDD

> 日期：2026-08-01  
> 状态：实施中（时间轴、后置配音入口、字幕与合成基座已执行）
> 目标版本：2.8  
> 适用范围：本集声音时间轴、导演分镜、角色配音、分镜视频和字幕合成  
> 上位文档：`docs/资产图工作区与Markdown双链创作图谱升级SDD.md`、`docs/并行创作分支与Markdown阅读导航优化SDD.md`  
> 相关 Skill：`skills/jc-script-storyboard/SKILL.md`、`skills/jc-voice-design/SKILL.md`

## 1. 一句话目标

让导演分镜先决定每个镜头的叙事节奏、对白情绪和无对白动作时长，再生成本集角色对白，最后按完整时间轴生成视频、字幕和成片；声音库属于角色，可跨集复用。

本 SDD 只负责修正“声音与镜头时间关系”。资产 ID、项目 Wiki、三类资产并行生成等规则继续沿用上位文档。

## 2. 覆盖旧合同

以下旧规则不再适用于剧情片、多角色对白和无对白动作场景：

- 不能再要求“先生成整集配音，只有真实配音时长可用后才能生成导演分镜”；
- 不能把整集配音时长作为所有镜头的唯一时长来源；
- 不能把没有台词的动作镜头从时间轴中省略；
- 不能为了得到时长给无对白镜头添加旁白或虚构台词。

新的时间关系以本 SDD 和更新后的 `jc-script-storyboard` Skill 为准。

## 3. 最终制作流程

```text
确认剧本（可直接导入第一集 Markdown）
  -> 识别角色
  -> 角色声音设计
  -> 建立/选择角色声音库
  -> 角色、场景、道具资产
  -> 导演分镜与镜头时间轴
  -> 本集多角色对白配音
  -> 分镜图
  -> 分镜视频
  -> 按最终音频生成字幕
  -> FFmpeg 合成成片
```

声音库先于资产和分镜建立；本集台词配音必须在导演分镜完成后生成，并在视频生成前可用。

## 4. 角色声音库

### 4.1 角色绑定

每个角色绑定稳定的 `voiceProfileId`。声音档案属于角色，不属于单集台词，也不随项目临时创建。

用户可选择两种来源：

1. **设计声音**：根据角色资料和五项声音设定建立基础音色；
2. **克隆声音**：从应用级音色库选择可用参考音色，再作为该角色的基础音色。

### 4.2 情绪样音

每个角色声音库至少保留一组常用情绪参考样音，每种约 5-6 秒。首批情绪包括：平静、开心、悲伤、愤怒、惊讶、紧张、恐惧、克制、坚定；项目可按剧情增减，但不能为每句台词临时重新设计角色音色。

样音是角色声音库资产，不是本集正式对白。样音记录：

- `voiceProfileId`
- `emotion`
- `intensity`
- `audioPath`
- `durationMs`
- `model`
- `status`

## 5. 导演分镜时间轴合同

### 5.1 分镜输入

导演分镜 Skill 接收：

- 已确认剧本原文；
- `targetDuration`：项目或本集目标时长；
- 已确认比例、视觉风格、镜头节奏和资产 ID；
- 可选 `actualDuration`：已经存在的本集对白真实时长。

没有 `actualDuration` 时，导演仍然必须生成完整时间轴，不能阻塞在配音阶段。

### 5.2 节拍分类

每个 `storyBeat` 必须标记为：

- `dialogue`：包含原文对白；
- `action`：走路、转身、拿取、对视、停顿、环境揭示或其他无对白动作。

`action` 节拍必须写明开始状态、动作发展、结束状态和目标时长。无对白不等于零时长。

### 5.3 有对白镜头

每个有对白镜头必须记录：

- 对白角色；
- 对应原文台词；
- 声音情绪；
- 情绪强度；
- 语速；
- 停顿与重音；
- 对白时长：已有配音时填写真实值，否则填写估算值并标记“待配音确认”；
- 是否需要口型或动作配合。

导演可以根据戏剧节奏在对白前后保留反应、呼吸和动作空间，不能把台词音频机械铺满整个镜头。

### 5.4 无对白镜头

每个无对白镜头必须记录：

- 动作节拍；
- 目标播放时长；
- 是否需要自然环境音或动作音；
- `对白角色：无`；
- `对应台词：无`；
- `口型/动作配合：不适用`。

无对白镜头的时长由导演节奏、动作完成所需时间和镜头构图决定，不等待配音，也不伪造声音来占时长。

### 5.5 时长规则

- `playDuration` 是镜头在本集时间轴中的目标播放时长；
- `generationDuration` 是媒体模型实际生成时长，仍只能使用 `4 / 6 / 8` 秒；
- `playDuration` 不超过 8 秒；不足 4 秒时生成 4 秒，合成阶段裁剪；
- 有对白镜头在配音完成后用真实对白时长校准；
- 无对白镜头保留导演设定的目标时长；
- 全部镜头时长之和形成 `timelineDuration`，不要求等于对白音频时长；
- 若对白总时长短于 `timelineDuration`，空余部分由动作、反应、呼吸和环境声占据；
- 若对白总时长超过镜头预算，标记为 `needs-review`，由导演重新分配镜头时长或调整语速，不静默截断台词。

## 6. 本集多角色配音

导演分镜确认后，应用按镜头台词清单提交本集配音任务：

1. 根据 `voiceProfileId` 选择角色声音库；
2. 根据镜头的情绪、强度、语速和停顿选择对应样音或声音参数；
3. 只为有对白镜头生成正式台词音频；
4. 无对白镜头不生成空白音频；
5. 为每句音频记录真实时长、镜头 ID、角色 ID、台词版本和模型；
6. 生成后回填镜头时间轴，发现超出预算时进入人工确认；
7. 已完成的角色或台词失败时只重试失败项，不重做整个声音库。

本集配音是“镜头约束下的正式对白”，不重新设计角色基础音色。

## 7. 视频与字幕

### 7.1 分镜视频

分镜视频读取：

- 镜头画面提示词；
- 视频提示词；
- 资产 ID；
- `playDuration` 与 `generationDuration`；
- 有对白时的说话角色、情绪和口型/动作要求；
- 无对白时的动作节拍和环境音要求。

视频模型生成的原始声音不进入成片。最终声音只来自本集正式配音和明确加入的环境音/动作音。

### 7.2 字幕

字幕在本集正式配音和视频片段都确认后生成：

- 字幕文本来自确认剧本中的对白，不来自模型生成视频声音；
- 字幕起止时间来自正式对白音频时间轴；
- 无对白动作镜头不生成字幕；
- 使用项目默认字体、字号、颜色、位置和描边标准；
- 字幕文件进入项目 Wiki，并与角色、台词、音频和镜头建立链接。

### 7.3 成片

FFmpeg 按镜头顺序拼接视频，丢弃视频原声，加入正式配音、环境音和字幕。合成结果记录：

- `timelineDuration`
- 实际成片时长
- 音频轨道清单
- 字幕文件路径
- 当前视频片段版本

## 8. Wiki 结构

```text
项目 Wiki/
├── 文稿/确认文稿.md
├── 声音/角色声音设计.md
├── 声音/角色/角色名.md
├── 声音/声音库/voiceProfileId.md
├── 声音/配音任务/episode-001.md
├── 分镜/导演总览.md
├── 分镜/镜头/shot-001.md
├── 字幕/episode-001.srt.md
└── 成片/episode-001.md
```

正向链：

`角色 -> 声音档案 -> 镜头台词 -> 配音音频 -> 字幕 -> 成片`

反向链由应用计算：

`声音档案 -> 使用它的角色和配音任务`  
`镜头 -> 对应台词、资产、音频、视频和字幕`

## 9. 状态和失效规则

```text
声音库：draft -> approved
分镜：draft -> needs-review -> approved
本集配音：pending -> running -> ready -> needs-review
视频：pending -> running -> ready
字幕：pending -> ready
成片：pending -> ready
```

| 修改内容 | 必须失效 | 保留 |
| --- | --- | --- |
| 角色声音设定或 `voiceProfileId` | 本集配音、字幕、成片 | 剧本、资产、分镜 |
| 分镜台词/情绪/语速/镜头时长 | 受影响台词、视频、字幕、成片 | 声音库、未受影响镜头 |
| 无对白动作时长 | 受影响镜头视频、字幕、成片 | 声音库、其他镜头配音 |
| 资产版本 | 引用该资产的分镜图、视频、成片 | 角色声音库和台词 |
| 正式配音音频 | 字幕、成片 | 声音库、分镜结构 |
| 字幕样式 | 成片 | 角色声音库、配音、视频 |

任何失败只标记对应子任务，不回滚已经成功的其他角色、镜头或音频。

## 10. UI 最小改动

不新增第四栏。沿用三栏结构：

- 中栏展示声音库、镜头时间轴、本集配音、字幕和成片结果；
- 右栏只操作当前阶段；
- 分镜阶段展示每镜的对白/无对白标记和时间字段；
- 本集配音阶段展示角色、台词、情绪、时长和失败项；
- 字幕阶段只提供默认样式确认和重新生成；
- 已有声音库和已生成音频不能因为切换页面而消失。

## 11. 实施顺序

1. 以更新后的 `jc-script-storyboard` Skill 作为分镜字段来源；
2. 扩展分镜 Markdown 和结构化状态，保存声音与时间轴字段；
3. 实现按镜头台词的多角色本集配音任务；
4. 回填真实对白时长并处理 `needs-review`；
5. 视频生成读取镜头时间轴和声音字段；
6. 生成字幕时间轴；
7. 合成并写回项目 Wiki；
8. 用一个含对白、无对白动作和多角色的实际项目验收。

## 12. 验收标准

1. 直接导入剧本可以开始声音设计，不强制先生成新文稿；
2. 四个角色可以各自建立并复用声音库；
3. 有对白镜头完整记录角色、台词、情绪、语速、停顿和时长；
4. 无对白镜头有明确动作时长，不产生虚假台词或空白配音任务；
5. 本集配音发生在导演分镜之后、视频生成之前；
6. 对白音频真实时长能回填时间轴，超出预算时可人工处理；
7. 字幕只来自正式对白音频和确认剧本；
8. 最终成片只使用当前项目的声音、视频和字幕版本；
9. 重试某句台词、某个镜头或字幕时，不重复提交其他已成功任务；
10. 重启应用后，项目 Wiki 能恢复声音档案、镜头时间轴、配音、字幕和成片关系。

## 13. 明确不做

- 不要求所有剧情都必须有对白；
- 不用整集对白音频决定无对白动作镜头时长；
- 不为无对白镜头生成虚假旁白或占位台词；
- 不在本 SDD 内决定 Qwen3-TTS 与 IndexTTS2 的最终默认模型；
- 不在本阶段加入口型同步算法；只记录口型/动作配合要求，为后续视频模型适配保留字段；
- 不引入第二套项目状态机或独立数据库；
